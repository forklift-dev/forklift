Forklift объединяет привычные задачи Git в одном окне. Изучайте коммиты, добавляйте в индекс отдельные строки,
разрешайте конфликты, ищите по истории и находите коммит, внёсший ошибку, не теряя из виду граф.
Для работы с локальным репозиторием учётная запись не нужна; сетевые функции подключаются по необходимости.

## Оформление на ваш вкус

Один репозиторий в трёх других встроенных темах. В Forklift есть **20 встроенных тем**, пользовательские темы,
акцентные цвета, **семь стилей графа**, а также настройка ширины панелей и колонок.

## Почему Forklift

- **Вся история перед глазами.** Виртуализированный граф показывает ветки, теги, авторов и рабочую копию. Ищите по сообщению, автору, хешу, файлу или содержимому и переходите прямо к найденному коммиту.
- **Точный состав коммита.** Просматривайте изменения рядом, в одной колонке, по фрагментам или целиком; добавляйте в индекс и отменяйте изменения отдельных файлов, фрагментов и строк. Последний коммит можно дополнить через amend.
- **Сложные операции в том же окне.** Merge, rebase, cherry-pick, revert, reset, интерактивный rebase и bisect доступны рядом со встроенным трёхсторонним редактором конфликтов. Bisect можно проходить вручную или запустить проверочную команду и следить за её выводом.
- **Контроль над действиями.** Поддерживаемые операции можно отменить и повторить; перед необратимыми действиями приложение запрашивает подтверждение. При переключении ветки локальные изменения можно сохранить во временный stash и восстановить. Журнал операций показывает команды Git и причины ошибок.
- **Удобный для вас способ работы.** Палитра команд и настраиваемые сочетания клавиш, встроенный терминал, внешние редакторы и инструменты сравнения, несколько репозиториев и рабочих деревьев во вкладках. Наблюдение за файлами обновляет интерфейс после изменений в других программах.
- **Локальная работа без входа.** Открытие, поиск и изменение локального репозитория не требуют авторизации. Необязательные подключения к хостингам добавляют работу с запросами на слияние, задачами и удалёнными репозиториями; учётные данные хранятся в защищённом хранилище ОС, если оно доступно.
- **Помощь AI по запросу.** В Настройках → Интеграции можно выбрать скачанную модель Ollama, свой ключ OpenAI API или установленный CLI Codex, Claude Code, OpenCode либо Qwen Code. Перед каждым запросом Forklift спрашивает разрешение и предупреждает о возможной плате за токены; предложения не изменяют файлы автоматически.

## Скачать Forklift

Предварительные сборки появляются на [странице релизов](https://github.com/forklift-dev/forklift/releases) после успешной сборки для Linux, Windows и macOS.

| Платформа | Текущий пакет |
|---|---|
| Linux x64 | AppImage |
| Windows x64 | Установщик и ZIP |
| macOS на Apple silicon | DMG и ZIP |

Эти бета-сборки пока не подписаны и не нотариально заверены. При первом запуске операционная система может запросить подтверждение.

## Сборка из исходников

Потребуются **Node.js 22.12 или новее** и инструменты сборки нативных модулей Git. Модули собираются для той же
операционной системы и архитектуры процессора, на которой будет запущен Forklift.

| Платформа | Инструменты |
|---|---|
| Linux | `build-essential`, `python3`, `perl`, `libkrb5-dev`; для Ubuntu 22.04 также `clang-15` |
| macOS | Xcode Command Line Tools, `python3` |
| Windows | Visual Studio 2022 Build Tools (Desktop C++), `python3` |

```bash
npm ci
npm run dev
```

При `npm ci` нативные модули пересобираются для Electron 45. На Linux OpenSSL 3 собирается из исходников; на macOS
и Windows скрипт загружает пакет OpenSSL с проверкой SHA-256. Чтобы получить установочный пакет, выполните
`npm run dist` на целевой платформе. В Ubuntu 22.04 запускайте `npm ci` с переменными
`CC=clang-15 CXX=clang++-15`: они нужны для заголовков V8 из Electron 45.

В репозитории также есть скрипты подготовки платформ:

```powershell
# Windows: установить недостающие инструменты и собрать установщик и ZIP
powershell -ExecutionPolicy Bypass -File scripts\build-windows.ps1
```

```bash
# macOS: при необходимости установить Node, пересобрать модули и создать DMG и ZIP
bash scripts/build-macos.sh
```

## Разработка

| Команда | Назначение |
|---|---|
| `npm run dev` | Запустить приложение с горячим обновлением |
| `npm run build` | Собрать Electron-приложение в `out/` |
| `npm run typecheck` | Проверить TypeScript основного процесса и интерфейса |
| `npm run lint` | Проверить исходники и тесты с oxlint |
| `npm test` | Запустить модульные и интеграционные тесты в среде Node внутри Electron |
| `npm run test:e2e` | Запустить сквозные тесты настольного приложения |
| `npm run dist` | Создать пакет для текущей платформы |
| `npm run rebuild:native` | Пересобрать нативные модули после обновления Electron |

Скриншоты для README создаются на временном Git-репозитории в отдельном профиле приложения. После сборки их можно
обновить командой `node scripts/capture-readme.mjs`; на Linux без экрана используйте
`xvfb-run -a node scripts/capture-readme.mjs`.

### Архитектура вкратце

```text
основной процесс    сервисы Git и основное хранилище состояния Redux
       ↓            типизированные команды и обновления состояния через IPC
preload             ограниченный API через contextBridge
       ↓
интерфейс           React и доступная только для чтения копия состояния
```

Интерфейс работает с изоляцией контекста, в песочнице и без доступа к Node.js. Операции Git выполняются
последовательно для каждого репозитория; нативные сервисы и команды Git работают вне процесса интерфейса.
Границы компонентов и принятые решения описаны в [архитектуре](docs/architecture.md), а выполненные и будущие
задачи перечислены в [документации проекта](docs/README.md).
