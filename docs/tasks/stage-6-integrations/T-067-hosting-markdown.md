# T-067. Техдолг: markdown в описаниях и комментариях PR и issues

## Цель

Решение владельца (2026-10-23): записать техдолгом и сделать позже. Описания и комментарии pull requests и
issues (T-065, потом GitVerse, GitHub, GitLab) пишут в markdown, а приложение показывает их простым текстом:
`**жирный**`, списки, код и ссылки видны как разметка. Нужна безопасная отрисовка markdown, близкая к тому, как
это выглядит на сервере.

## Контекст

- Сейчас текст выводится как есть (`src/renderer/src/components/HostingView.tsx`, `.hosting-text` с
  `white-space: pre-wrap`); `#123` уже превращается в ссылку внутри приложения (`IssueRefs`).
- Текст приходит с сервера и пишется чужими людьми — это недоверенные данные. Владелец за безопасность (решение
  2026-10-23 по T-065: сертификаты и внешние ссылки остаются как есть).
- Окно открывает внешние ссылки только по https (`setWindowOpenHandler` в `src/main/window.ts`), CSP окна не
  пускает внешние картинки и скрипты — это не ослаблять.
- Тот же вывод пригодится для README/описаний в других местах (не обязательно в этой задаче).

## Этапы

- [ ] Отрисовка markdown (CommonMark + таблицы, списки задач, зачёркивание из GFM) в React-элементы, **без**
      сырого HTML и без `dangerouslySetInnerHTML` (например, react-markdown без rehype-raw; выбор библиотеки и её
      размер — в «Нюансы»)
- [ ] Ссылки: https — во внешнем браузере через существующий обработчик; `#123`, `!123`, упоминания `@user` и
      sha коммитов — внутри приложения, как сейчас `IssueRefs`; прочие схемы (`javascript:`, `file:` и т. п.) — текстом
- [ ] Блоки кода с подсветкой (Monaco уже есть — его токенайзер, без нового движка), инлайн-код
- [ ] Картинки: не загружать с внешних адресов (CSP и утечка IP/трекинг); показать ссылкой «картинка: имя» —
      или решить с владельцем в «Нюансах»
- [ ] Стили — токены темы, контраст во всех темах
- [ ] Тесты: юнит на опасные вводы (HTML, `javascript:`-ссылки, огромный текст), сквозная проверка отрисовки в
      виде PR/issue

## Критерии готовности

- Описания и комментарии выглядят как на сервере (кроме картинок), никакой HTML из текста не исполняется и не
  вставляется, CSP и обработчик ссылок не ослаблены
- Юнит/интеграционные тесты, `npm run typecheck`, `lint`, `test`, сквозной набор в `npm run test:e2e` — зелёные
