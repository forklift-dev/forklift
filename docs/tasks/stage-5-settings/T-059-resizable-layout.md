# T-059. Изменяемая ширина колонок графа и боковых панелей

## Цель

Пожелание владельца (2026-10-23): мышью менять ширину колонок графа (Branch/Tag, Graph, Commit message,
Author, Date, SHA) и ширину панелей слева (ветки/теги) и справа (изменения/детали коммита) от графа и от
редактора (diff, история файла, конфликты), как в GitKraken. Размеры запоминаются.

## Контекст

- Сейчас ширины зашиты в CSS (`src/renderer/src/styles.css`): раскладка рабочей области
  `.workspace { grid-template-columns: 220px minmax(0, 1fr) 320px }`, колонки графа `.cell.refs` 170 px,
  `.cell.author` 140 px, `.cell.date` 150 px, у графа ширина по числу дорожек (до 16), сообщение — остаток.
- Уже есть образец перетаскивания: высота встроенного терминала (`terminal-splitter` в `App.tsx`, запоминается в
  localStorage).
- В GitKraken колонка графа ещё и прокручивается по горизонтали, если дорожек больше ширины (видно на скриншоте
  владельца, T-058).

## Этапы

- [x] Разделители между левой панелью, центром и правой панелью (перетаскивание, двойной клик — ширина по
      умолчанию, минимальные/максимальные ширины, клавиатура: фокус на разделителе и стрелки)
- [x] Свернуть/развернуть левую и правую панели (кнопка и сочетание клавиш из реестра T-052)
- [x] Колонки графа: перетаскивание границ в заголовке, двойной клик — по содержимому; показать/скрыть колонки
      (Author, Date, SHA) из меню заголовка
- [x] Колонка графа с горизонтальной прокруткой, когда дорожек больше её ширины
- [x] Запоминание: глобально или на репозиторий (решить и записать в «Нюансы»), переживает перезапуск
- [x] Узкое окно (≥ 900 px): панели не ломают раскладку, сообщение коммита не уходит в ноль
- [x] Сквозной набор: перетаскивание разделителей и колонок, сохранение после перезапуска

## Критерии готовности

- Ширины меняются мышью и клавиатурой, сохраняются; виртуализация и выделение строк в графе работают
- Юнит/интеграционные тесты, `npm run typecheck`, `lint`, `test`, сквозной набор в `npm run test:e2e` — зелёные

## Нюансы

- Связано с T-058 (стили графа меняют ширину дорожки и высоту строки) — делать после неё или учитывать.
- 2026-10-23: размеры — **общие для всех репозиториев** (как в GitKraken), хранятся в localStorage окна
  (`forklift.layout`, как высота терминала; `src/renderer/src/layout.ts`), переживают перезапуск. Если понадобятся
  свои на каждый репозиторий — ключ по корню репозитория.
- 2026-10-23: панели: разделители между левой панелью, центром и правой панелью (`Splitter`: мышь, стрелки ±16 px,
  Shift ±64, Home/End, Enter или двойной клик — ширина по умолчанию). Пределы: левая 160–520 px, правая 240–720 px;
  в узком окне CSS ещё ограничивает их 32 % и 40 % ширины окна, центру остаётся не меньше 360 px. Свернуть:
  Mod+J (левая) и Mod+K (правая), как у GitKraken; повторное нажатие или перетаскивание разделителя возвращает.
  Панели справа и слева от редактора (diff, история, конфликты) — те же самые панели.
- 2026-10-23: колонки графа: ручки на границах в заголовке (Branch/Tag и Graph тянутся вправо, Author/Date/SHA —
  влево; двойной клик — по умолчанию, у Graph — «по дорожкам»), меню заголовка (правый клик): скрыть/показать
  Author, Date, SHA, «Fit the graph column to its lanes», «Reset columns». Колонка Graph уже, чем её дорожки, —
  прокручивается вбок: Shift+колесо (или горизонтальная прокрутка тачпада) над графом и полоса с ползунком под
  колонкой.
- 2026-10-23: проверено: сквозной набор `layout` (13 проверок: перетаскивание и клавиатура, Ctrl+J/K, колонки,
  меню заголовка, прокрутка графа, сохранение после перезапуска); в харнесс добавлен `drag()`.
