# T-057. Верхняя панель в стиле GitKraken

## Цель

Переделать тулбар так, чтобы по виду и раскладке он был близок к GitKraken (пожелание владельца 2026-10-23):
слева «хлебные крошки» репозиторий ▾ / ветка ▾, по центру плоские кнопки действий с иконкой и подписью,
справа поиск и меню. Сейчас тулбар — ряд текстовых кнопок с рамками (`src/renderer/src/components/Toolbar.tsx`).

## Контекст

Как устроено у GitKraken 12.6 (по `gitkraken/resources/app.asar` → `src/css/styles.css`, темы
`src/main/static/defaultThemes/*.jsonc-default`, `themeBases/base.jsonc`; берём раскладку и размеры, код и
картинки свои):

- Высота панели 48 px (`--toolbar-height`), снизу граница 1 px. Три фона: `toolbar__bg1` — сама панель,
  `toolbar__bg0` (темнее) — наведение и открытое меню, `toolbar__bg2` (светлее) — выпадающие меню. В тёмной
  теме ≈ #313641 / #282c35 / #3e4452. Кнопки без рамок и скруглений.
- **Слева** — крошки: каждая часть — кнопка ≥110 px с мелкой подписью сверху (11 px, `text-secondary`:
  «repository», «branch») и названием 15 px (репозиторий — жирным), стрелка ▾; части разделены «стрелкой»
  (уголок фоном следующей части, `:after` с `border-left`). Меню репозитория: недавние, «открыть», «клонировать»,
  все репозитории; меню ветки — переключение с фильтром. Для подмодуля/worktree — родитель отдельной крошкой.
- **Центр** — группа кнопок по центру: ширина 48 px, на всю высоту, иконка ~16 px сверху и подпись 11 px
  снизу (`toolbar-title`), наведение — `bg0`, неактивные — `text-disabled`. Набор: Undo, Redo | Pull (у неё узкая
  14 px стрелка ▾ рядом: fetch, pull merge/rebase), Push, Branch, Stash, Pop.
- **Справа** — поле поиска 200 px (у нас: поиск по истории / палитра Ctrl+P), Terminal, журнал/уведомления,
  меню приложения (Preferences, профиль, тема).
- Прогресс операций — жёлтая полоска 4 px вдоль низа панели (у нас сейчас текст с процентом в тулбаре и тост).

## Этапы

- [ ] Токены темы для панели: `toolbar-bg`, `toolbar-hover`, `toolbar-menu` (+ значения во всех 6 темах и в
      пользовательских — см. T-051), высота 48 px
- [ ] Крошки «репозиторий ▾ / ветка ▾»: меню репозитория (недавние, Open, Clone, New, вкладки), меню ветки
      (поиск по веткам, checkout, создать ветку); ahead/behind рядом с веткой; подмодуль/worktree — родитель
- [ ] Центральная группа: Undo, Redo, Pull ▾, Push, Branch, Stash, Pop — иконка + подпись, состояния
      disabled/наведение/выполняется (спиннер на кнопке), подсказки с сочетаниями из T-052
- [ ] Справа: поиск (открывает поиск по истории / finder), Terminal, журнал операций, меню (Preferences, профиль,
      тема, команды); Refresh и Close уходят в меню репозитория/палитру
- [ ] Прогресс fetch/pull/push — полоска вдоль низа панели (+ Cancel по клику), тосты остаются
- [ ] Узкое окно: подписи кнопок скрываются, крошки сокращаются (минимальная ширина окна 900 px)
- [ ] Обновить сквозные наборы, завязанные на старые кнопки тулбара (`.toolbar button` по тексту), скриншоты
      панели во всех темах в отчёт

## Критерии готовности

- Панель визуально близка к GitKraken (сравнение скриншотов владельцем), все прежние действия доступны
- Контраст текста на новых фонах ≥ 4.5:1 во всех встроенных темах (тест T-051)
- Юнит/интеграционные тесты, `npm run typecheck`, `lint`, `test`, сквозной набор в `npm run test:e2e` — зелёные

## Нюансы

- 2026-10-23: иконки — codicons (уже в проекте); у GitKraken свои (Font Awesome Pro), их не берём.
- Если владелец пришлёт скриншот своего GitKraken (тема, плотность) — сверять с ним.
