# T-084. AI: сообщение коммита, ревью, объяснение конфликта (локально)

## Цель

Предложение (2026-10-26): помощь AI через то, что у пользователя уже есть — установленные CLI-агенты (Claude Code, Codex, Gemini CLI…) или свой API-ключ/Ollama: сообщение коммита по staged-diff, ревью изменений, объяснение коммита и конфликта. Так сделано у AngKorGit (`packages/core/src/ai/*`, `src-tauri/src/ai_cli.rs`, MIT).

## Контекст

- В «Сознательно не делаем» (README) исключены AI-функции GitKraken — облачные, через их сервер; здесь — без нашего сервера, запросы идут от пользователя к выбранному им провайдеру.

- [x] Сообщение коммита, ревью staged, объяснение коммита и конфликта; отмена; явное согласие перед каждым запросом

- Юнит/интеграционные тесты, `npm run typecheck`, `lint`, `test`, сквозной набор в `npm run test:e2e` — зелёные

## Нюансы

- 2026-10-26: **вопрос владельцу**: отменяет ли это решение об исключённых AI-функциях (те были облачными GitKraken).
- 2026-10-26: решение владельца: делаем по предложенному плану; AI без нашего сервера (CLI-агенты пользователя, его ключ API, Ollama) не противоречит исключению облачных AI-функций GitKraken.
- 2026-10-27: локальная Ollama использует `127.0.0.1:11434`, имя установленной модели задаётся в Preferences → Integrations. Перед чтением кода проверяется список моделей: модель должна быть скачана (`size > 0`) и не иметь remote-метаданных. Это важно: [Ollama умеет отправлять запросы к облачным моделям даже через локальный сервер](https://github.com/ollama/ollama/blob/main/docs/cloud.mdx). Запрос запускается только после отдельного подтверждения. Ответ — предложение: сообщение коммита пользователь применяет вручную; ревью и объяснения не изменяют файлы. Дифф ограничен 48 КБ. Отмена прерывает запрос; закрытие окна тоже.
- 2026-10-27: по просьбе владельца в диалоге согласия явно указаны токены: локальная Ollama не использует платные API-токены; для будущих CLI/API-провайдеров понадобится отдельное предупреждение и подтверждение перед каждым запросом.
- 2026-10-27: CLI-провайдеры выбираются из фиксированного списка и запускаются без shell из нового временного каталога. Codex работает в read-only sandbox, Claude Code без встроенных и MCP-инструментов, Qwen Code без инструментов и с лимитами, OpenCode через plan-агента с исходным текстом во временном файле. Это не даёт CLI получить путь к открытому репозиторию через рабочую директорию. Конфигурация и авторизация CLI остаются пользовательскими; запрос может расходовать оплачиваемые токены, о чём отдельно предупреждает диалог перед запуском.
- 2026-10-27: OpenAI API использует личный ключ из отдельного зашифрованного хранилища и Responses API с `store: false`. Имя модели задаётся пользователем. Ключ не передаётся в renderer и не записывается в настройки или журнал операций.
- 2026-10-27: проверены `npm run typecheck`, `npm run lint`, `npm test` (584 пройдено, 1 пропущен) и `npm run test:e2e` (52/52 набора). В тестах CLI и OpenAI подменены, чтобы не тратить токены; фактическая работа зависит от установленного и авторизованного провайдера пользователя.
