# T-090. Платформа совместного перевода

## Цель

При появлении активных переводчиков дать им веб-интерфейс с контекстом, предложениями и ревью, сохранив репозиторий источником истины для каталогов.

## Контекст

T-086 и T-088 создают достаточный для старта процесс через pull request. Платформа имеет смысл, когда ручные PR станут неудобны. Конкретный сервис и условия размещения ещё не выбраны.

## Этапы

- [ ] Сравнить подходящие платформы по поддержке формата каталогов, контекста, plural-форм, Git-синхронизации, ревью и условиям размещения.
- [ ] Зафиксировать решение владельца о сервисе и доступе сообщества; описать роли переводчика и проверяющего.
- [ ] Настроить импорт, обновление исходных строк и экспорт переводов через проверяемые pull request или эквивалентный процесс.
- [ ] Проверить на тестовом языке, что синхронизация не теряет контекст, параметры, plural-формы и изменения вне платформы.
- [ ] Обновить руководство переводчиков и порядок разрешения конфликтов синхронизации.

## Критерии готовности

- Участник может предложить перевод через веб-интерфейс; принятие проходит проверку и оставляет историю изменений в репозитории.
- Пробная двусторонняя синхронизация не удаляет существующие переводы и не обходит ревью.
