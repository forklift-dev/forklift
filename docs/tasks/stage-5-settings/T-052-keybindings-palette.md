# T-052. Сочетания клавиш, палитра команд, нечёткий поиск

## Цель

Единый реестр команд; настраиваемые сочетания клавиш; палитра команд (Ctrl/Cmd+Shift+P); нечёткий поиск по файлам, веткам, коммитам (Ctrl/Cmd+P).

## Контекст

- В GitKraken: Keybinding 43, Fuzzy/Palette 74 строки (по `strings.json`); их реализация — ориентир по поведению, код свой.

## Этапы

- [ ] Реестр команд (id, название, обработчик, доступность)
- [ ] Keybindings: значения по умолчанию по ОС + пользовательские, редактор сочетаний
- [ ] Палитра команд
- [ ] Нечёткий поиск (fuzzy, как fuzzaldrin) по файлам рабочей копии, веткам, тегам, коммитам

## Критерии готовности

- Любое действие приложения доступно из палитры; сочетания переназначаются
- Юнит/интеграционные тесты, `npm run typecheck`, `lint`, `test`, сквозной набор в `npm run test:e2e` — зелёные
