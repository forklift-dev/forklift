# T-052. Сочетания клавиш, палитра команд, нечёткий поиск

## Цель

Единый реестр команд; настраиваемые сочетания клавиш; палитра команд (Ctrl/Cmd+Shift+P); нечёткий поиск по файлам, веткам, коммитам (Ctrl/Cmd+P).

## Контекст

- В GitKraken: Keybinding 43, Fuzzy/Palette 74 строки (по `strings.json`); их реализация — ориентир по поведению, код свой.

## Этапы

- [x] Реестр команд (id, название, обработчик, доступность)
- [x] Keybindings: значения по умолчанию по ОС + пользовательские, редактор сочетаний
- [x] Палитра команд
- [x] Нечёткий поиск (fuzzy, как fuzzaldrin) по файлам рабочей копии, веткам, тегам, коммитам

## Критерии готовности

- Любое действие приложения доступно из палитры; сочетания переназначаются
- Юнит/интеграционные тесты, `npm run typecheck`, `lint`, `test`, сквозной набор в `npm run test:e2e` — зелёные

## Нюансы

- GitKraken: `src/keyBindings/{shared,linux,darwin,win32}.json` — ориентир по набору.
- 2026-10-23: команды и их сочетания по умолчанию — `src/shared/keybindings.ts` (≈45 команд: вкладки, экраны,
  терминал, undo/redo, fetch/pull/push, stash, stage/unstage/discard all, ветка/тег на HEAD, поиск в истории,
  Go to HEAD, темы). `Mod` = ⌘ на macOS и Ctrl на Linux/Windows; Redo: ⇧⌘Z/⌘Y и Ctrl+Shift+Z/Ctrl+Y. По образцу
  GitKraken: Mod+L fetch, Mod+B ветка, Mod+Shift+S/U stage/unstage all, Mod+Shift+M сообщение коммита.
- 2026-10-23: реестр — в окне (`src/renderer/src/commands.ts`): компоненты регистрируют обработчики, пока
  смонтированы (App — общие, рабочая область — команды репозитория); недоступные сейчас команды не показываются в
  палитре и их сочетание проходит дальше. Один слушатель клавиш (фаза capture) вместо прежних разрозненных.
  Сочетания читаются по физической клавише (`KeyboardEvent.code`): работают и в русской раскладке. Клавиши без
  Ctrl/Alt/⌘ (кроме F1–F24) приложение не перехватывает; Undo/Redo не срабатывают в полях ввода и редакторах.
- 2026-10-23: свои сочетания — настройка `keys.bindings` (в settings.json: команда → список, `[]` — без
  сочетаний), Preferences → Keyboard shortcuts: фильтр, «+» записывает нажатое сочетание, × удаляет, Reset
  возвращает по умолчанию; занятое другой командой сочетание отклоняется с подсказкой. Меню приложения (macOS)
  пока не показывает сочетания — если нужно, вместе с T-054/T-003.
- 2026-10-23: палитра (Mod+Shift+P) — нечёткий поиск (`src/shared/fuzzy.ts`: подпоследовательность, бонусы за
  начало слова/CamelCase/подряд идущие/имя файла) по «Категория: команда», показывает сочетание. Поиск (Mod+P) —
  файлы рабочей копии (`git ls-files -co --exclude-standard`), ветки, удалённые ветки, теги и коммиты (тема —
  нечётко, или начало sha; ищет main по всей истории с текущим фильтром графа). Enter — показать (коммит в графе,
  diff изменённого файла, история неизменённого), Shift+Enter — checkout ветки / история файла, «>» — команды.
- 2026-10-23: проверено: юнит-тесты (сочетания, нечёткий поиск, поиск коммитов, список файлов, настройка) и
  сквозной набор `commands` (25 проверок).
