# T-055. Аватары авторов

## Цель

Аватары в графе и деталях: по умолчанию цветные инициалы локально; Gravatar — только по опции в настройках (решение владельца 2026-10-23).

## Этапы

- [x] Инициалы + стабильный цвет по email
- [x] Опция Gravatar: загрузка в main (sha256 email), кеш на диске, отказ при офлайне
- [x] CSP: img-src для Gravatar только при включённой опции

## Критерии готовности

- Без опции нет ни одного сетевого запроса за аватарами
- Юнит/интеграционные тесты, `npm run typecheck`, `lint`, `test`, сквозной набор в `npm run test:e2e` — зелёные

## Нюансы

- 2026-10-23: по умолчанию — инициалы (первое и последнее слово имени, иначе первая буква email; Unicode) в
  круге цвета линии графа темы, выбранного по FNV-хешу email (`src/shared/avatars.ts`): один автор — один цвет,
  в любой теме. В графе (у имени автора) и в деталях коммита (автор, коммиттер).
- 2026-10-23: Gravatar — настройка UI → «Load avatars from Gravatar» (выключена). Запросы делает только main
  (`net.fetch`, учитывает прокси системы): `https://gravatar.com/avatar/<sha256(email)>?s=80&d=404`, не больше 4
  одновременно, ответ ≤ 256 КБ и только png/jpeg/gif/webp. Кеш — `userData/avatars` на 7 дней, «нет картинки»
  тоже кешируется; при офлайне/ошибке — инициалы и новая попытка не раньше чем через 10 минут.
- 2026-10-23: CSP окна не меняется вообще: картинки приходят в окно как `data:` URL через IPC (`img-src 'self'
  data:` уже было), так что окно не может обратиться к gravatar.com ни при какой настройке. Это строже, чем «img-src
  только при включённой опции» из этапов.
- 2026-10-23: проверено: юнит-тесты (`avatars/service.test.ts`: инициалы, цвета, выключено — ни одного запроса,
  sha256-адрес, кеш картинок и промахов, неделя, офлайн) и сквозной набор `avatars` (8 проверок; включённый
  Gravatar сквозным набором не проверяется — это были бы настоящие запросы в интернет).
