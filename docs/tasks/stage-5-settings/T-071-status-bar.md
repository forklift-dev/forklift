# T-071. Строка статуса внизу окна

## Цель

Пожелание владельца (2026-10-26): нижняя полоса статуса: переключатель стиля графа и сведения о системе и репозитории. У AngKorGit в строке статуса — ветка, время последнего fetch, число изменений, AI-провайдер, масштаб, версия.

## Контекст

- Верхняя панель — T-057; стиль графа сейчас в Preferences (`ui.graphStyle`, T-058).
- Что уже известно в состоянии: версия git (`app.gitCli`), ветка и ahead/behind, изменения, операция, LFS, сетевые операции.

- [x] Сведения: ветка и ahead/behind, число изменений, время последнего fetch (auto-fetch), операция в процессе, версия git, наличие commit-graph и размер истории
