# T-071. Строка статуса внизу окна

## Цель

Пожелание владельца (2026-10-26): нижняя полоса статуса: переключатель стиля графа и сведения о системе и репозитории. У AngKorGit в строке статуса — ветка, время последнего fetch, число изменений, AI-провайдер, масштаб, версия.

## Контекст

- Верхняя панель — T-057; стиль графа сейчас в Preferences (`ui.graphStyle`, T-058).
- Что уже известно в состоянии: версия git (`app.gitCli`), ветка и ahead/behind, изменения, операция, LFS, сетевые операции.

## Этапы

- [ ] Полоса статуса (тема, высота, скрыть/показать командой палитры)
- [ ] Переключатель стиля графа (меню с предпросмотром)
- [ ] Сведения: ветка и ahead/behind, число изменений, время последнего fetch (auto-fetch), операция в процессе, версия git, наличие commit-graph и размер истории
- [ ] Системное: память приложения, работающие git-процессы (с отменой), версия Forklift

      языках интерфейса, цитата (см. «Нюансы»)

- Юнит/интеграционные тесты, `npm run typecheck`, `lint`, `test`, сквозной набор в `npm run test:e2e` — зелёные
