# T-100. Переключатель экспериментальных функций

## Цель

Добавить глобальную галочку «Экспериментальные функции» в Preferences → General. По умолчанию выключена; при выключении функции и все их точки входа скрыты. Включение — явный opt-in пользователя.

## Контекст

Владелец решил добавить четыре экспериментальные функции: центр очистки веток ([T-101](../stage-2-git-core/T-101-branch-cleanup.md)), действия над диапазоном коммитов ([T-102](../stage-3-history/T-102-commit-ranges.md)), диагностику здоровья репозитория ([T-103](../stage-4-repositories/T-103-repository-health.md)) и рабочие места задач ([T-104](../stage-4-repositories/T-104-task-workspaces.md)). Настройка только глобальная; не доступна как repo override.

## Этапы

- [x] Добавить глобальную boolean-настройку с default `false`, переводом и описанием.
- [x] Скрывать все четыре UI-точки входа при выключенном значении.
- [x] Проверить сохранение после перезапуска и отсутствие утечки в repo settings.
- [x] Добавить e2e на переключатель и скрытие всех четырёх экспериментальных функций.

## Критерии готовности

- В чистом профиле галочка выключена.
- Значение хранится в общих настройках и одинаково для всех репозиториев.
- Все четыре точки входа и связанные панели невидимы при выключенной галочке; это проверяется в e2e.
- После включения входы отображаются, после выключения немедленно скрываются.
- typecheck, lint, i18n, test и test:e2e проходят.

## Нюансы

- 2026-10-28: настройка не включает отправку телеметрии и не должна сама выполнять Git-операции.
- Дочерние T-101…T-104 реализованы с явным opt-in; все точки входа скрыты по умолчанию.
- 2026-10-28: проверены typecheck, lint, i18n, связанные unit/e2e сценарии. Полные test и test:e2e остаются в финальной проверке общего набора.
