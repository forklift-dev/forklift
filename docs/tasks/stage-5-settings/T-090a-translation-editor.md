# T-090a. Локальная таблица переводов

## Цель

Дать переводчикам отдельную страницу, где исходные строки и переводы видны по колонкам, можно добавить свой язык и выгрузить готовый JSON-каталог.

## Выполнено

- [x] Таблица исходного английского каталога и имеющихся языков, поиск, фильтр пропусков и постраничный просмотр.
- [x] Добавление колонки по коду и самоназванию языка, редактирование строк и форм множественного числа.
- [x] Локальное сохранение черновика, импорт и экспорт JSON с проверкой ID, параметров и plural-форм.
- [x] Команды `translations:dev` и `translations:build`, инструкции для переводчиков на английском и русском.
- [x] Проверка редактора в отдельном окне Electron и модульные тесты формата экспорта.

## Критерии готовности

- Новый язык можно заполнить на странице и получить `xx.json`, который проходит `i18n:check` после добавления языка в `locales.json`.
- Данные остаются в браузере после перезагрузки страницы; импорт каталога и выгрузка не требуют сервера.

## Нюансы

- Это локальный статический инструмент. Публикация, аккаунты, совместное редактирование и ревью остаются в T-090. Черновики привязаны к браузеру и адресу страницы; переводчику нужно скачать JSON для переноса на другое устройство.

## Промт

```text
Проверь T-090a: запусти npm run translations:dev, добавь язык, заполни простую и plural-строку, выгрузи JSON и проверь его через npm run i18n:check после регистрации языка. Затем проверь typecheck, lint, test и test:e2e.
```
