# T-054. Уведомления и журнал операций

## Цель

Тосты об итогах операций, журнал всех git-операций приложения (команда, вывод, длительность) для диагностики.

## Контекст

- В GitKraken: Notifications 100 строк; LogView в GitKraken (по `strings.json`); их реализация — ориентир по поведению, код свой.

## Этапы

- [x] Тосты (успех/ошибка/прогресс долгих операций)
- [x] Журнал: все вызовы GitCli и nodegit-операций, просмотр и экспорт
- [x] Ошибки с подробностями из журнала

## Критерии готовности

- Каждая операция видна в журнале; ошибки объяснимы
- Юнит/интеграционные тесты, `npm run typecheck`, `lint`, `test`, сквозной набор в `npm run test:e2e` — зелёные

## Нюансы

- 2026-10-23: журнал — в памяти main (`src/main/log/operationLog.ts`, последние 3000 записей). Два вида записей:
  операция (команда окна: `remote:push`, `stash:push`…, со временем, длительностью, итогом и ошибкой) и запуск
  git (командная строка, код выхода, длительность; вывод — для изменяющих и неудачных команд, хвост до 8 КБ).
  Запуски git связываются со своей операцией через AsyncLocalStorage. Частые чтения (history:rows, diff:file,
  commit:details…) как операции не пишутся; nodegit-чтения (обновление репозитория) видны как операция
  `repo:refresh`/`repo:open`, отдельные вызовы libgit2 не логируются. Фоновый auto-fetch пишется как `auto-fetch`.
- 2026-10-23: пароли в URL маскируются (`https://ada:***@…`) в заголовках и выводе; окружение (askpass-токен)
  не пишется. Журнал не реплицируется в состояние (только счётчик `app.logVersion`), окно читает записи командой.
  Экспорт — текстом в выбранный файл (права 0600).
- 2026-10-23: просмотр — экран «Operation log» (палитра: «Help: Show the operation log»): операции новыми сверху,
  раскрытие с git-командами и выводом, фильтр, «Errors only», показ read-only команд, Export…, Clear.
- 2026-10-23: ошибки остаются в баннере (как раньше), но с кнопкой Details — открывает журнал на этой операции
  (IPC-ошибка несёт `logId`). Отдельных тостов для ошибок нет, чтобы не дублировать баннер.
- 2026-10-23: тосты (слева внизу: справа кнопка Commit и панель diff): «Pushed · repo», «Changes stashed · repo»… для завершённых операций (кнопка
  Log), гаснут через 4 с; настройка General → «Show notifications». Прогресс fetch/pull/push и clone — тостом с
  фазой, процентом и Cancel, пока операция идёт.
- 2026-10-23: проверено: юнит-тесты (`operationLog.test.ts`: связь git с операцией, ошибки, маскирование,
  ограничение размера) и сквозной набор `log` (13 проверок).
