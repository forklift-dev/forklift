# T-074. Локализация интерфейса (i18n)

## Цель

Пожелание владельца (2026-10-26): перевод интерфейса, в первую очередь на русский. Ни у одного конкурента нет i18n (GitComet #373, AngKorGit #64 — китайский) — заметное отличие для нашей аудитории (GitVerse).

## Контекст

- Строки интерфейса сейчас на английском прямо в компонентах; сообщения git — на английском (LANGUAGE=en_US для разбора вывода, T-012).

## Этапы

- [x] Выбрать механизм (свои словари с ключами и plural-формами или библиотека; ICU MessageFormat для русских склонений)
- [x] Вынести строки из компонентов, команд палитры, меню, уведомлений
- [x] Русский перевод; язык — по системе или в Preferences
- [x] Даты и числа по локали; сообщения git не переводить (их разбирает код)
- [x] Проверка в тестах: нет непереведённых ключей, длинные русские строки не ломают раскладку

## Критерии готовности

- Интерфейс полностью на русском при выборе языка; переключение без перезапуска или с явным перезапуском
- Юнит/интеграционные тесты, `npm run typecheck`, `lint`, `test`, сквозной набор в `npm run test:e2e` — зелёные

## Нюансы

- 2026-10-26: е2е-тесты ищут элементы по английским подписям — перевести их на aria-атрибуты/ключи или запускать на английском.
- 2026-10-26: порядок владельца — T-074 первой из его списка (T-074 → T-070 → T-071 → T-072 → T-073), чтобы не выносить строки новых задач дважды.
- 2026-10-26: механизм — свои словари без библиотеки (`src/shared/i18n`, правила и глоссарий — [docs/i18n.md](../../i18n.md)): ключ — английский текст в месте использования (`t('Discard changes')`), русские переводы по частям приложения в `strings/<часть>.ts`; тип `Message` — ключи русского словаря, поэтому строка без перевода не компилируется. Множественное число — `Intl.PluralRules` (one/few/many), контекст — `context|text`, даты — `formatDate`. ICU MessageFormat не понадобился: склонения по числу закрываются формами, остальное — целыми предложениями. Язык — настройка `ui.language` (system/en/ru); смена без перезапуска: корень `App` перерисовывается целиком (memo нигде нет), main переводит свои сообщения по той же настройке. Сквозные проверки запускаются с `--lang=en-US`.
- 2026-10-26: решение владельца по терминам — «смешанно»: названия git-команд латиницей (Push, Pull, Fetch, Rebase, Cherry-pick, Stash), сущности по-русски (коммит, ветка, тег), пояснения по-русски. Языки — английский и русский; другие — отдельным решением владельца (добавить язык = добавить словари).
- 2026-10-26: рутинный вынос строк по частям отдаю Codex CLI (разрешение владельца), промты — по docs/i18n.md, каждый дифф проверяю сам.
