# T-087. Подключение новых языков интерфейса

## Цель

Добавлять локаль без изменения каждой части приложения; давать пользователю выбор языка и безопасно показывать неполный перевод.

## Контекст

`src/shared/i18n/index.ts` содержит фиксированный список `en/ru`, `src/shared/settings.ts` — варианты настройки `ui.language`, а `tests/e2e/suites/i18n.mjs` проверяет только русский и английский. Тип `Message` сейчас зависит от русского словаря.

## Этапы

- [x] Вынести список поддерживаемых локалей и их самоназвания в единый реестр; использовать его в настройках, main и renderer.
- [x] Подключать каталог нового языка без правок существующих каталогов и компонентов; сохранить определение языка системы и ручной выбор без перезапуска.
- [x] При отсутствии строки или формы множественного числа показывать английский источник; явно учитывать этот случай в проверках покрытия.
- [x] Проверить даты, числа и формы множественного числа через `Intl` для каждой локали; проверить длинные подписи и доступность переключателя языка.
- [x] Добавить проверочный пример третьей локали или тестовую фикстуру, подтверждающую весь путь от каталога до UI.

## Критерии готовности

- Третий язык можно добавить каталогом и записью в реестре; он выбирается в настройках и по системной локали.
- Неполный перевод работает без пустых строк и необработанных `{параметров}`; русский остаётся полным.
- `npm run typecheck`, `npm run lint`, `npm test` и `npm run test:e2e` проходят.

## Нюансы

- 2026-10-27: поддержка письма справа налево требует отдельной проверки раскладки; не объявлять её готовой только на основании поддержки `Intl`.
- 2026-10-27: `locales.json` задаёт коды и самоназвания; Vite загружает каталоги `*.json` автоматически. `de` — частичный пример (5 строк из 1370). Проверка печатает покрытие и проверяет плейсхолдеры и формы для каждого каталога. Английский fallback выбирает форму по английским правилам.
- 2026-10-28: `typecheck`, `lint`, `i18n:check` и полный `npm test` прошли (585 тестов, 1 пропущен). Первый полный e2e-прогон дал 50/52 без сохранённого текста двух сбоев; повторный полный прогон прошёл 52/52. Набор i18n отдельно тоже прошёл.
