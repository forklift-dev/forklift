# T-050. Настройки: хранилище, окно Preferences, внешние инструменты

## Цель

Настройки приложения и репозитория с сохранением между запусками и окно Preferences. Отдельно и
подробно — **выбор внешних программ**: редактор, терминал, diff-инструмент, merge-инструмент
(пожелание владельца 2026-10-23). Сейчас они только определяются автоматически (T-013, T-014).

## Контекст

- В GitKraken: Preferences — 380 строк интерфейса; разделы General, Profiles, UI, Editor, Terminal,
  External Tools, Integrations, Gitflow, LFS, SSH, GPG.
- У нас уже есть: `ExternalTools` (редактор/терминал, принимает `editor`/`terminal` как `ToolCommand`),
  `DiffTools` (git difftool/mergetool, выбирает настроенный в git инструмент).

## Этапы

- [x] Хранилище: JSON в `userData/settings.json`, схема с типами, значениями по умолчанию и версией,
      миграции; атомарная запись (временный файл + rename); повреждённый файл → резервная копия и значения по умолчанию
- [x] Срез `settings` в реплицируемом состоянии; IPC `settings:update(patch)` с проверкой по схеме в main
- [x] Окно Preferences (отдельный экран/вкладка в приложении): навигация по разделам, поиск по настройкам
- [ ] Разделы:
  - [ ] **General** — переносится в задачи, которые дают этим настройкам смысл: восстановление вкладок (T-041),
        auto-fetch и prune (T-042)
  - [x] **Git**: путь к git (авто/свой, «Обзор…»), проверка версии, глобальные user.name/email (с предупреждением, что это git config)
  - [x] **Diff**: режим (Split/Inline; Hunk/File — T-028), игнор пробелов, перенос, свёртка неизменённого, контекст
  - [x] **Editor**: шрифт, размер, табуляция (перенос — в Diff, он же переключатель в панели diff)
  - [ ] **Terminal**: shell, шрифт — вместе со встроенным терминалом (T-027)
  - [ ] **UI**: тема (T-051), плотность, аватары (T-055)
- [x] **External tools**:
  - **Editor**: «Автоопределение» | выбор из найденных (code, cursor, codium, zed, subl…) | своя команда
  - **Terminal**: «Автоопределение» | выбор из найденных по ОС/рабочему столу | своя команда
  - **Diff tool** и **Merge tool**: «Как в git config» (`diff.tool`/`merge.tool`) | выбор из доступных в
    `git difftool --tool-help` (графические) | своя команда с `$LOCAL $REMOTE $BASE $MERGED`
    (передаётся через `-c difftool.forklift-custom.cmd=…`, как для VS Code в T-014)
  - Своя команда: исполняемый файл (кнопка «Обзор…») + аргументы с плейсхолдерами `{file}`, `{line}`, `{dir}`;
    подстановка поаргументно (без shell)
  - Кнопка **«Test»** у каждого инструмента: редактор/терминал — на тестовом файле/папке во временной папке;
    diff/merge — во временном репозитории (изменённый файл / настоящий конфликт), результат текстом
  - Кнопка «Save to git config…» для diff/merge (с подтверждением; по умолчанию храним в настройках приложения)
- [x] Настройки репозитория (переопределения по репозиторию) — в том же `settings.json`, ключ — корень репозитория;
      переопределяются внешние инструменты; переключатель «All repositories / This repository»; идентичность — `git config --local`
- [x] Применение без перезапуска; тесты хранилища, миграций, проверки схемы, подстановки команд

## Критерии готовности

- Выбранные редактор/терминал/diff/merge используются кнопками Edit, Terminal, Ext, Merge; кнопка
  «Проверить» сообщает понятный результат; настройки переживают перезапуск
- Юнит/интеграционные тесты, `npm run typecheck`, `lint`, `test`, сквозной набор в `npm run test:e2e` — зелёные

## Нюансы

- Пути к программам и аргументы приходят из окна — в main проверяются (тип, длина, существование файла);
  выполнение только через ProcessRunner без shell.
- Секреты (токены интеграций, T-06x) в settings.json не хранятся — только в системном хранилище (`safeStorage`).
- 2026-10-23: **одна декларативная схема** `src/shared/settings.ts` (`SETTING_FIELDS`): из неё выводятся типы значений,
  значения по умолчанию, проверка (`parseSettingValue` — и для IPC, и для файла), разделы и подписи Preferences, поиск
  и список ключей, которые может переопределить репозиторий (`repo: true`). Новая настройка = одна запись в схеме +
  место, где она используется. Следующие задачи (T-041, T-042, T-027, T-051, T-055) добавляют свои разделы так же.
- 2026-10-23: в файле хранятся **только отличия от значений по умолчанию** — улучшенные умолчания доходят до
  существующих пользователей. Неизвестный ключ или неверное значение → значение по умолчанию + сообщение в Preferences.
  Файл от более новой версии → копия `settings.json.newer-backup` до первой перезаписи. Повреждённый JSON →
  `settings.json.damaged-<время>` и баннер с объяснением.
- 2026-10-23: своя diff/merge-команда: git выполняет `difftool.<tool>.cmd` через `sh` (`eval`, и в Git for Windows
  тоже), поэтому строка собирается `gitToolCommand`: каждый аргумент в двойных кавычках с экранированием `\ " ` $`,
  живыми остаются только `$LOCAL $REMOTE $BASE $MERGED`. Тест проверяет это настоящим `sh` (в том числе `$(…)` и
  обратные кавычки остаются текстом).
- 2026-10-23: проверка программ при сохранении: своя команда должна находиться (по PATH или полному пути);
  путь к git — только полный путь или пусто. Позже программа может пропасть — тогда понятная ошибка при запуске
  с подсказкой «Preferences → External tools».
- 2026-10-23: при смене пути к git версия определяется заново (строка «Using git X» в разделе Git и на пустом экране).
- 2026-10-23: настройки diff раньше лежали в localStorage окна; теперь это общие настройки (переключатели в панели
  diff пишут их же). Старое значение из localStorage не переносится — приложение ещё не выпускалось.
- 2026-10-23: найден и исправлен попутный баг: глифы codicon (кнопки в списке изменений) появлялись только после
  открытия первого diff — Monaco генерирует CSS иконок при создании редактора. Теперь CSS иконок создаётся при старте
  (`src/renderer/src/icons.ts`).
- 2026-10-23: экран Preferences закрывается Esc только когда фокус в нём (обработчик на самом экране помечает событие
  `preventDefault`), чтобы открытый под ним diff не закрылся тем же нажатием.
- 2026-10-23: «Test» для diff/merge ждёт закрытия окна инструмента; для merge нерешённый конфликт — нормальный исход теста.
- 2026-10-23: проверено: юнит/интеграционные тесты (схема, файл, сервис, ToolActions на реальном git с временным
  `GIT_CONFIG_GLOBAL`, ExternalTools/DiffTools с настройками), сквозной набор `settings` (21 проверка) в dev и в
  упакованной сборке.
