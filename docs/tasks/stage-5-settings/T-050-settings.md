# T-050. Настройки: хранилище, окно Preferences, внешние инструменты

## Цель

Настройки приложения и репозитория с сохранением между запусками и окно Preferences. Отдельно и
подробно — **выбор внешних программ**: редактор, терминал, diff-инструмент, merge-инструмент
(пожелание владельца 2026-10-23). Сейчас они только определяются автоматически (T-013, T-014).

## Контекст

- В GitKraken: Preferences — 380 строк интерфейса; разделы General, Profiles, UI, Editor, Terminal,
  External Tools, Integrations, Gitflow, LFS, SSH, GPG.
- У нас уже есть: `ExternalTools` (редактор/терминал, принимает `editor`/`terminal` как `ToolCommand`),
  `DiffTools` (git difftool/mergetool, выбирает настроенный в git инструмент).

## Этапы

- [ ] Хранилище: JSON в `userData/settings.json`, схема с типами, значениями по умолчанию и версией,
      миграции; атомарная запись (временный файл + rename); повреждённый файл → резервная копия и значения по умолчанию
- [ ] Срез `settings` в реплицируемом состоянии; IPC `settings:update(patch)` с проверкой по схеме в main
- [ ] Окно Preferences (отдельный экран/вкладка в приложении): навигация по разделам, поиск по настройкам
- [ ] Разделы:
  - **General**: открывать последние репозитории при запуске (вкл. по умолчанию), auto-fetch и интервал, prune
  - **Git**: путь к git (авто/свой), проверка версии, глобальные user.name/email (с предупреждением, что это git config)
  - **Diff**: режим (Split/Inline/Hunk/File), игнор пробелов, перенос, контекст
  - **Editor**: шрифт, размер, табуляция, перенос
  - **Terminal**: shell, шрифт (для T-027)
  - **UI**: тема (T-051), плотность, аватары (T-055)
- [ ] **External tools**:
  - **Editor**: «Автоопределение» | выбор из найденных (code, cursor, codium, zed, subl…) | своя команда
  - **Terminal**: «Автоопределение» | выбор из найденных по ОС/рабочему столу | своя команда
  - **Diff tool** и **Merge tool**: «Как в git config» (`diff.tool`/`merge.tool`) | выбор из доступных в
    `git difftool --tool-help` (графические) | своя команда с `$LOCAL $REMOTE $BASE $MERGED`
    (передаётся через `-c difftool.forklift-custom.cmd=…`, как для VS Code в T-014)
  - Своя команда: исполняемый файл (кнопка «Обзор…») + аргументы с плейсхолдерами `{file}`, `{line}`, `{dir}`;
    подстановка поаргументно (без shell)
  - Кнопка **«Проверить»** у каждого инструмента: найден ли, на тестовых файлах (временная папка)
  - Опция «записать выбор в git config» для diff/merge (по умолчанию — нет, храним в настройках приложения)
- [ ] Настройки репозитория (переопределения по репозиторию) — хранятся в userData по пути репозитория
- [ ] Применение без перезапуска; тесты хранилища, миграций, проверки схемы, подстановки команд

## Критерии готовности

- Выбранные редактор/терминал/diff/merge используются кнопками Edit, Terminal, Ext, Merge; кнопка
  «Проверить» сообщает понятный результат; настройки переживают перезапуск
- Юнит/интеграционные тесты, `npm run typecheck`, `lint`, `test`, сквозной набор в `npm run test:e2e` — зелёные

## Нюансы

- Пути к программам и аргументы приходят из окна — в main проверяются (тип, длина, существование файла);
  выполнение только через ProcessRunner без shell.
- Секреты (токены интеграций, T-06x) в settings.json не хранятся — только в системном хранилище (`safeStorage`).
