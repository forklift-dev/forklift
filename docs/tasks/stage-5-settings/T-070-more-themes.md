# T-070. Больше тем интерфейса и стилей графа

## Цель

Пожелание владельца (2026-10-26): больше встроенных тем приложения и стилей графа коммитов. У AngKorGit — 16 тем с акцентами и масштабом интерфейса, у GitComet — встроенные и пользовательские JSON-темы (`docs/research/competitors-2026-10.md`).

## Контекст

- Темы — `src/shared/themes.ts` (≈ 60 токенов, 6 тем, проверка контраста), пользовательские темы файлами (T-051).
- Стили графа — данные в `src/renderer/src/graphStyles.ts` (kraken, classic, compact, metro; T-058).

## Этапы

- [x] Подобрать набор тем (тёмные и светлые; популярные палитры — Solarized, Nord, Dracula, Gruvbox, One Dark/Light, GitHub, Catppuccin…) с проверкой контраста
- [x] Акцентный цвет и масштаб интерфейса (zoom) в Preferences
- [x] Новые стили графа (например: «тонкий» с маленькими узлами, «плотный» без аватаров, «рельсы» с прямыми углами), выбор цвета дорожек из палитры темы
- [x] Предпросмотр темы и стиля графа в Preferences без применения

## Критерии готовности

- Все темы проходят тест контраста; стили графа — тест производительности (10 тыс. коммитов) как в T-058
- Юнит/интеграционные тесты, `npm run typecheck`, `lint`, `test`, сквозной набор в `npm run test:e2e` — зелёные

## Нюансы

- 2026-10-26: какие палитры брать и сколько — решить при реализации; лицензии палитр проверить (большинство MIT).
- 2026-10-26: предложение владельца — взять темы AngKorGit (MIT). Взяты палитры всех 14 его тем (`packages/design-system/src/themes.css`, HSL → hex, `src/shared/themePalettes.ts`) и его колесо цветов дорожек; уведомление MIT — `THIRD_PARTY_NOTICES.md` (кладётся в ресурсы сборки). Имена свои (правило T-051 — без чужих торговых марок): Dusk/Dawn (Сумерки/Рассвет), Studio Dark/Light, Harbor Dark/Light, Graphite, Neon Night, Cocoa, Cream, Nocturne, Fjord, Amber Dark/Light — по мотивам VS Code, GitHub, One Dark, Tokyo Night, Catppuccin, Dracula, Nord, Ayu. Итого 20 встроенных тем (12 тёмных, 8 светлых).
- 2026-10-26: у AngKorGit тема — это ~15 цветов (фоны, текст, синтаксис); остальные ~60 токенов выводит `paletteTheme` в `src/shared/themes.ts`: наведение, рамки, полосы прокрутки, ярлыки, статусы, diff и конфликты. Каждый цвет текста и линий он сдвигает по светлоте (оттенок и насыщенность сохраняются), пока тот не наберёт 4,5:1 к фонам, где его показывают (3:1 для дорожек и фокуса), — поэтому все темы проходят тест контраста по построению.
- 2026-10-26: акцентный цвет `ui.accent` — «Из темы» или 8 цветов (синий, зелёный, фиолетовый, розовый, красный, оранжевый, золотой, бирюзовый, как в AngKorGit): перекрашивает акцент, фокус, основные кнопки и blame, подгоняя их до читаемости в любой теме (тест: 20 тем × 8 акцентов); дорожки графа, выделение и diff не трогает. Масштаб `ui.zoom` (50–200 %, по умолчанию 100) — `setZoomFactor` окна; команды «Увеличить / уменьшить / сбросить масштаб» на Ctrl+= / Ctrl+- / Ctrl+0.
- 2026-10-26: стили графа — Thin (тонкий: узлы 3 px, линии 1,25 px), Rails (рельсы: прямые углы, новый тип поворота `square`), Ribbon (лента: полоса вдоль строки, точки, ярлыки цвета дорожки); всего 7. Цвета дорожек — из палитры темы (`graph-0…9`), у новых тем свои. Производительность — теперь в наборе `graph-styles`: 10 000 коммитов, 200 прыжков по 900 px, медиана и p95 — 33–34 мс (два кадра) во всех 7 стилях.
- 2026-10-26: предпросмотр без применения уже был (T-051, T-058): карточки тем рисуют приложение и редактор в своих цветах, карточки стилей — граф; применяется только по щелчку.
- 2026-10-26: попутно: уведомлений о лицензиях npm-зависимостей (React, Monaco и др.) в сборке нет — `THIRD_PARTY_NOTICES.md` пока только с AngKorGit; полный список стоит собирать при упаковке (T-081).
