# T-096a. Проверка новых релизов на GitHub

## Цель

Сообщать о новом опубликованном выпуске Forklift и открывать его страницу в браузере. Загрузка и установка остаются в T-056.

## Выполнено

- [x] Проверка публичного списка GitHub Releases после запуска упакованного приложения, с таймаутом и выключателем в «Общих» настройках.
- [x] Ручная проверка в карточке «О программе» с сообщением о новой, текущей или недоступной для платформы версии и ошибке сети.
- [x] Уведомление со ссылкой на релиз и возможностью скрыть его на время текущего запуска.
- [x] Учитываются опубликованные prerelease, поскольку текущий workflow делает все выпуски предварительными; черновики, ссылки вне репозитория и релизы без пакета для текущих ОС и архитектуры пропускаются.
- [x] Модульные проверки выбора релиза и сквозная проверка интерфейса.

## Нюансы

- Сравнивается версия приложения из `package.json` с основными числами тега. Повторная CI-сборка той же версии (`v0.5.0-build.*`) не считается обновлением: установленный пакет не хранит номер сборки.
- Пока есть только Linux x64 (AppImage), Windows x64 (NSIS) и macOS arm64 (DMG). Для других архитектур ручная проверка сообщает, что пакета нет.
- Данные о релизах запрашиваются напрямую у публичного GitHub API без токена. При автоматической проверке ошибка сети не отвлекает пользователя; при ручной выводится сообщение.

## Критерии готовности

- Упакованное приложение показывает новый совместимый опубликованный релиз и ведёт на его страницу GitHub.
- Отключение фоновой проверки сохраняется, ручная проверка остаётся доступной.
- Нет автоматической загрузки или установки.
