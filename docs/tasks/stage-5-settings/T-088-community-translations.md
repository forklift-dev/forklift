# T-088. Процесс переводов от сообщества

## Цель

Дать участнику понятный путь от выбора строки до pull request, а сопровождающему — понятный способ проверить и принять перевод.

## Контекст

Правила русской локализации уже записаны в [docs/i18n.md](../../i18n.md), но инструкции для новых языков и внешних переводчиков нет. README на английском и русском ведутся отдельно от UI-каталогов.

## Этапы

- [x] Написать руководство: как добавить язык, перевести существующий, посмотреть результат и отправить pull request.
- [x] Описать контекст, переменные, plural-формы, терминологию, непереводимые имена и отдельный порядок перевода README/документации.
- [x] Добавить короткий шаблон PR или чеклист ревью перевода со ссылкой на автоматические проверки и визуальную проверку длинных строк.
- [x] Сделать диагностические сообщения проверок понятными человеку, который не знает TypeScript; при необходимости добавить команду локальной проверки каталогов.
- [x] Проверить инструкцию на пробном изменении одного перевода и добавлении неполной локали.

## Критерии готовности

- Участник может подготовить перевод, следуя только руководству, без редактирования кода приложения.
- CI сообщает о пропущенных ключах, неверных параметрах и plural-формах; неполный новый язык допускается по установленным правилам.
- Руководство доступно из README и описывает, кто и как проверяет предложения сообщества.
