## Цель

Несколько профилей (имя/email для коммитов, SSH-ключ, настройки) с быстрым переключением; генерация и выбор SSH-ключей; подпись коммитов GPG/SSH.

## Контекст

- В GitKraken: Profile 57, SSH/GPG 191 строка (по `strings.json`); их реализация — ориентир по поведению, код свой.

## Этапы

- [ ] Профили: user.name/email на уровне репозитория или глобально по выбору
- [ ] SSH: использование ssh-agent, выбор ключа (core.sshCommand), генерация ed25519 (`ssh-keygen`)
- [ ] Подпись: commit.gpgsign, gpg.format=ssh/openpgp, выбор ключа; проверка подписи в деталях коммита
