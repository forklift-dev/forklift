# T-089. Устойчивые идентификаторы строк интерфейса

## Цель

Отвязать идентичность перевода от английской формулировки: редактура исходного текста не должна терять переводы и историю изменений.

## Контекст

Сейчас `t('English text')` использует сам текст как ключ, а различный смысл одного текста обозначается префиксом `context|text`. Это удобно в коде, но усложняет поддержку переводов по мере роста сообщества.

## Этапы

- [x] Определить схему устойчивых идентификаторов и правила миграции с сохранением контекста, текста, параметров и plural-форм.
- [x] Обеспечить временную совместимость старых вызовов и мигрировать их по частям приложения без одновременного массового переписывания.
- [x] Научить проверку каталогов выявлять повторные, неиспользуемые и переименованные идентификаторы.
- [x] Обновить руководство переводчиков и проверить, что смена английской формулировки не сбрасывает переводы.

## Критерии готовности

- У всех переводимых строк есть устойчивый идентификатор; одинаковые английские фразы с разным смыслом остаются различимыми.
- Изменение английского текста при прежнем смысле не меняет идентификатор и не удаляет существующие переводы.
- Обязательные проверки проекта и сквозные проверки локализации проходят.

## Нюансы

- 2026-10-27: миграция не должна автоматически считать исправленный смысл старой строки тем же сообщением: такое изменение требует нового идентификатора.
- 2026-10-28: все 1370 сообщений в `en.json` и `ru.json` перенесены на ID `msg.<16 hex>`, частичный `de.json` перенесён без потери переводов. `legacy.json` сохраняет исторический английский ключ и контекст; старые `t()` и `translate()` проходят через него. Первые вызовы в Preferences используют ID напрямую. При редактуре английского значения ID не меняется; изменение смысла требует нового ID.
- 2026-10-28: ID создаётся из исходного ключа командой `npm run i18n:id`; проверка не допускает его переименования, повторов, неизвестных и неиспользуемых ID. `i18n:sync` сохраняет текущий английский источник и не переписывает каталог при ошибке ID.
- 2026-10-28: сверка с предыдущим коммитом подтвердила сохранение всех значений: en 1370/1370, ru 1370/1370, de 5/5. `typecheck`, `lint`, `i18n:check`, полный `npm test` (587 пройдено, 1 пропущен) и `npm run test:e2e` (52/52 набора) прошли.
