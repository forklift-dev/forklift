# T-051. Темы приложения и редактора

## Цель

Несколько встроенных тем для **приложения** и отдельно для **редактора** (Monaco: diff, blame, конфликты),
плюс пользовательские темы. Пожелание владельца (2026-10-23): ориентироваться на дизайн GitKraken, но сделать
несколько разных тем. Общие принципы внешнего вида — [design.md](../../design.md).

## Контекст

- GitKraken: тема = JSONC `{ meta: { name, scheme: light|dark }, themeValues: { root: {...} } }`
  (`defaultThemes/*.jsonc-default`, `themeBases/base.jsonc`). Группы токенов: `text-*`, панели/разделители,
  выделенная строка, `graph-color-0…9` (линии графа), `code-*` (редактор, 10 цветов blame), конфликты
  (left/right/output), статистика +/−, прокрутка, кнопки, поля ввода, зоны перетаскивания, состояния PR.
- Берём **структуру групп** как ориентир; имена токенов и цвета — свои.
- Сейчас у нас: CSS-переменные в `styles.css`, светлая/тёмная по системе; Monaco `vs`/`vs-dark`.

## Этапы

- [x] Токены (CSS-переменные): фон/панели/границы, текст (normal/secondary/dimmed/bright/inverse), акцент,
      выделение, успех/предупреждение/ошибка, 10 цветов графа, статистика, конфликты, прокрутка, кнопки, поля
- [x] Встроенные темы приложения (минимум 6): **Forklift Dark** (по мотивам тёмной темы GitKraken: глубокий
      сине-серый), **Forklift Light**, **Dark High Contrast**, **Light High Contrast**, **Polar** (холодная
      северная палитра), **Sand** (тёплая палитра низкой контрастности)
- [x] Темы редактора (Monaco `defineTheme`): «Как у приложения» (по умолчанию) или отдельный выбор из встроенных
      (минимум 4: тёмная, светлая, высококонтрастная, тёплая); цвета diff (вставки/удаления), blame, конфликтов
- [x] Выбор в Preferences → UI: тема приложения («Как в системе» / конкретная), тема редактора; превью;
      применение мгновенно, без перезагрузки окна
- [x] Пользовательские темы: файлы JSONC в `userData/themes/`, формат как у встроенных (`extends` встроенной +
      переопределения), перечитывание при изменении файла, понятные ошибки разбора
- [x] Терминал (T-027) и граф (T-022) берут цвета из темы
- [x] Контраст: все пары текст/фон высококонтрастных тем ≥ 7:1, обычных ≥ 4.5:1 (проверка в тестах)
- [x] Сквозной набор: переключение тем, скриншоты каждой темы в отчёт

## Критерии готовности

- Переключение темы приложения и редактора мгновенно и полно (UI, diff, граф, терминал); пользовательская тема подхватывается
- Юнит/интеграционные тесты, `npm run typecheck`, `lint`, `test`, сквозной набор в `npm run test:e2e` — зелёные

## Нюансы

- Не использовать названия чужих торговых марок тем (Nord, Solarized, Dracula и т. п.) — свои имена.
- 2026-10-23: токены и темы — `src/shared/themes.ts` (≈60 токенов в группах surfaces/text/accent/status/refs/graph/
  stats/diff/conflicts/controls/code). Имена CSS-переменных = имена токенов (`--bg`, `--fg-muted`, `--graph-3`,
  `--code-keyword`…); в `styles.css` больше нет «зашитых» цветов, значения ставит окно на `<html>` при запуске (до
  первого рендера, поэтому вспышки другой темы нет).
- 2026-10-23: встроенные: Forklift Dark, Forklift Light, Dark High Contrast, Light High Contrast, Polar (тёмная
  холодная), Sand (светлая тёплая, мягкий контраст). Настройки Preferences → UI: `ui.theme` (System — Forklift
  Light/Dark по системе, или тема) и `ui.editorTheme` («Same as the app» или любая тема, включая свои). Карточки с
  превью, применение сразу.
- 2026-10-23: тема редактора — Monaco `defineTheme` (база vs/vs-dark/hc-black/hc-light по схеме, правила синтаксиса
  из `code-*`, цвета diff/выделения/прокрутки/виджетов), а её токены дополнительно ставятся на `.monaco-editor` и
  `.hunk-view`: декорации (конфликты, blame, File view) идут в цветах редактора, даже если он отличается от темы
  приложения.
- 2026-10-23: терминал берёт фон/текст/курсор/выделение из `code-*` темы приложения и перекрашивается на лету;
  16 ANSI-цветов — набор на тёмную и на светлую схему (в коде, не токены): программы опираются на роли цветов.
- 2026-10-23: свои темы — `userData/themes/*.jsonc` (папка создаётся при запуске, кнопка «Open themes folder»):
  `{ "meta": { "name": "…", "scheme"?: "light"|"dark", "extends"?: "<встроенная>" }, "tokens": { "accent": "#ff8800" } }`.
  JSONC (комментарии, висячие запятые), цвета `#rgb`/`#rrggbb`/`#rrggbbaa`. id — `user:<имя файла>`. Папка
  отслеживается (fs.watch, 150 мс), ошибки разбора — списком под выбором темы. Если выбранный файл удалён —
  тема «System» до его возвращения. Контраст своих тем не проверяется (это выбор пользователя).
- 2026-10-23: контраст: юнит-тест на все встроенные темы — текст (fg/muted/dimmed/акцент/статусы/синтаксис) на всех
  фонах, кнопки, выделение, diff-подсветка (с учётом прозрачности): ≥ 4.5:1, у High Contrast ≥ 7:1; линии графа и
  фокус ≥ 3:1. Самые низкие сейчас: обычные — 4.56 (кнопка Forklift Dark), высококонтрастные — 8.58.
- 2026-10-23: проверено: сквозной набор `themes` (17 проверок; скриншоты графа и diff в каждой теме, своей темы и
  Preferences → UI — в `tests/e2e/artifacts/themes/`).
