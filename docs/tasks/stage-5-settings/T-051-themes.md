# T-051. Темы

## Цель

Светлая, тёмная, высококонтрастные темы и пользовательские темы (JSONC, как в GitKraken), согласованная тема Monaco и терминала.

## Контекст

- В GitKraken: Theme 11 строк (по `strings.json`); их реализация — ориентир по поведению, код свой.

## Этапы

- [ ] Токены цветов (CSS-переменные) для всего UI
- [ ] Тема по системе / явный выбор
- [ ] Пользовательские темы: файлы JSONC в userData, перечитывание при изменении
- [ ] Темы Monaco и xterm из токенов

## Критерии готовности

- Переключение темы мгновенно и полно (UI, редактор, терминал)
- Юнит/интеграционные тесты, `npm run typecheck`, `lint`, `test`, сквозной набор в `npm run test:e2e` — зелёные

## Нюансы

- GitKraken хранит темы в `defaultThemes/*.jsonc-default` и `themeBases/base.jsonc` — формат можно взять как ориентир, свои цвета.
