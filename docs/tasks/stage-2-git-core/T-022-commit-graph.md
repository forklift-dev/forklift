# T-022. Граф коммитов и виртуализация списка

## Цель

Наглядный граф веток и слияний рядом со списком коммитов; плавная прокрутка десятков тысяч коммитов.

## Этапы

- [ ] Раскладка графа (lanes) по `parents` — вне React-рендера (main или worker), с тестами
- [ ] Отрисовка: SVG/canvas в строках списка
- [ ] Виртуализация списка
- [ ] Порционная загрузка истории вместо фиксированных 1000 коммитов
- [ ] История вне реплицируемого среза `repo` (иначе она копируется в окно при каждом изменении статуса)
