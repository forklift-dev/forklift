# T-026. Слежение за файлами и автообновление

## Цель

Состояние репозитория обновляется само при изменении файлов и при работе git из терминала.

## Этапы

- [ ] Watcher рабочего дерева и `.git` (HEAD, refs, index) через `nsfw` (GitKraken, MIT)
- [ ] Debounce ≈300 мс, объединение событий; игнор `.git/objects` и путей из `.gitignore`
- [ ] Без параллельных чтений: флаг «нужно ещё раз»; раздельное обновление статуса и истории
- [ ] Обновление при фокусе окна как запасной механизм; остановка при закрытии репозитория
- [ ] Предупреждение о лимите inotify на Linux
