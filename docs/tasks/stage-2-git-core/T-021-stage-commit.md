# T-021. Stage/unstage и коммит

## Цель

Индексировать и снимать с индекса файлы, создавать коммит с сообщением из UI.

## Этапы

- [ ] Команды `index:stage`, `index:unstage` (файл, список, всё) через nodegit `Index`
- [ ] `commit:create` с сообщением; автор из git config; amend — по согласованию
- [ ] Хуки `pre-commit`/`commit-msg`: libgit2 их не запускает — коммит через git CLI (T-012) или явный запуск хуков
- [ ] UI: чекбоксы/кнопки в панели изменений, поле сообщения коммита
- [ ] Подпись коммитов (GPG/SSH) — отдельное решение

## Нюансы

- Хуки — важное отличие libgit2 от git CLI; пользователи ожидают, что `pre-commit` сработает.
