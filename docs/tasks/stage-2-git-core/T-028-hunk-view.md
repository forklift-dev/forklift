# T-028. Hunk View и File View

## Цель

Режимы просмотра, как в GitKraken: **Hunk View** — только изменённые фрагменты с заголовками
(`@@ -a,b +c,d @@`) и кнопками Stage/Unstage/Discard у каждого; **File View** — файл целиком с подсветкой
изменённых строк (без второй панели).

## Контекст

- В GitKraken: Diff View / File View / Hunk View / Inline / Split (`strings.json`: FileViewPanel-*).
- Сейчас роль Hunk View выполняет «Collapse unchanged» Monaco; действия над фрагментами — иконки в «желобе» (T-021).

## Этапы

- [x] Переключатель режима: Split / Inline / Hunks / File (сохраняется в настройках `diff.layout`)
- [x] Hunk: фрагменты из line changes Monaco, заголовки `@@ -a,b +c,d @@`, кнопки действий, контекст 3 строки
- [x] File: одна панель Monaco, подсветка добавленных/изменённых строк, маркеры удалений, кнопки фрагментов в желобе
- [x] Выделение строк и действия T-021 работают во всех режимах (в Hunks — клик по строке, в File — выделение)
- [x] Сквозной набор в tests/e2e (`diff-layouts`)

## Критерии готовности

- Все режимы показывают одинаковые изменения; индексация из любого режима даёт одинаковый результат
- Юнит/интеграционные тесты, `npm run typecheck`, `lint`, `test`, `npm run test:e2e` — зелёные

## Нюансы

- 2026-10-23: во всех режимах изменения считает один и тот же diff Monaco: для Hunks и File редактор diff остаётся
  смонтированным, но скрыт (вне экрана). Поэтому фрагменты одинаковые, а действия идут теми же запросами T-021
  (хэши версий, `applyLineChanges`) — результат индексации от режима не зависит.
- 2026-10-23: в File видна новая версия файла; удалённые строки отмечены линией над местом удаления (подсказка —
  сколько строк). Выделение в File — только добавленные строки (удалённых в этой панели нет).
- 2026-10-23: прежний флажок «Split» в панели diff заменён списком режимов.
- 2026-10-23: проверено: юнит-тест заголовков, сквозной набор `diff-layouts` (8 проверок: одинаковые изменения,
  заголовки, контекст, stage фрагмента и строки из Hunks, stage фрагмента из File).
