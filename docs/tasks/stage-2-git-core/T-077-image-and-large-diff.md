# T-077. Diff изображений и больших файлов

## Цель

Предложение (2026-10-26): diff картинок (рядом, наложение, разница) и показ больших текстовых файлов вместо отказа (сейчас > 10 МБ — «File is too large to show»). Image diff есть у AngKorGit и GitComet; GitComet рассчитан на огромные файлы.

## Контекст

- `MAX_DIFF_FILE_BYTES` = 10 МБ (`src/shared/diff.ts`); бинарные файлы — «Binary file».

## Этапы

- [ ] Image diff: png/jpg/gif/webp/svg (svg — как картинка, без скриптов), режимы «рядом», «наложение» с ползунком, «разница»
- [ ] Большие текстовые файлы: постраничная загрузка или ограничение по строкам вместо отказа
- [ ] Размеры и форматы — сообщения о неподдерживаемых

## Критерии готовности

- Diff картинки и файла 50 МБ открываются; CSP не ослаблен (картинки — data:/blob: из main)
- Юнит/интеграционные тесты, `npm run typecheck`, `lint`, `test`, сквозной набор в `npm run test:e2e` — зелёные
