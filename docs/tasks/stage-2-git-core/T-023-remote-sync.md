# T-023. Fetch/pull/push и учётные данные

## Цель

Синхронизация с удалёнными репозиториями по HTTPS и SSH с прогрессом, отменой и
запросом учётных данных через UI приложения.

## Этапы

- [ ] Fetch/pull/push через git CLI (T-012) с `--progress`, прогресс в состояние
- [ ] Отмена операции (AbortSignal → убийство дерева процессов, T-010)
- [ ] Учётные данные: системный credential helper (Git Credential Manager, osxkeychain, libsecret);
      собственный `GIT_ASKPASS`-мост для запроса логина/пароля/passphrase в UI
- [ ] SSH: ssh-agent, ключи пользователя, known_hosts (запрос подтверждения нового хоста)
- [ ] Pull: стратегия merge/rebase/ff-only — **решение владельца**

## Нюансы

- У GitKraken askpass-мост — проприетарный `rust-socket-bridge`; нам нужен свой: маленький
  скрипт-askpass, который связывается с приложением (сокет/именованный канал) и получает ответ из UI.
- Секреты не хранить в состоянии и не логировать.

## Промт

```text
Задача docs/tasks/stage-2-git-core/T-023-remote-sync.md в статусе draft — сначала согласуй с владельцем
стратегию pull и подход к хранению учётных данных. Затем спроектируй askpass-мост (опиши дизайн в
задаче до реализации) и реализуй fetch/pull/push через git CLI-адаптер с прогрессом и отменой.
```
