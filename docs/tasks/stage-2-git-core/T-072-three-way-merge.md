# T-072. 3-way merge: панель BASE и выбор строк

## Цель

Пожелание владельца (2026-10-26): полноценное трёхстороннее слияние: ours, base, theirs и результат, выбор блоков и отдельных строк, авторазрешение простых конфликтов. У GitComet — 2- и 3-way merge с autosolve, у AngKorGit — выбор строк из сторон (MIT, `features/conflicts/ConflictResolver.tsx`).

## Контекст

- Сейчас — редактор конфликта T-025 (`ConflictView.tsx`): маркеры, «взять ours/theirs», база видна только внутри маркеров diff3.
- Версии файла (`:1:`, `:2:`, `:3:`) уже читаются для внешнего mergetool (T-014).

## Этапы

- [x] Раскладка: три панели (ours / base / theirs) над результатом, синхронная прокрутка
- [x] Взять блок или строку из стороны; оба варианта по порядку; правка результата вручную
- [x] Авторазрешение: изменения только с одной стороны, одинаковые с обеих сторон, пробелы
- [x] Навигация по конфликтам (следующий/предыдущий), счётчик, «Mark resolved»
- [x] Большие файлы и бинарные — отдельные сообщения

## Критерии готовности

- Сквозной набор: конфликт с базой, выбор строк, авторазрешение, сохранение и продолжение merge
- Юнит/интеграционные тесты, `npm run typecheck`, `lint`, `test`, сквозной набор в `npm run test:e2e` — зелёные

## Нюансы

- 2026-10-26: код GitComet (AGPL) не переносить; AngKorGit (MIT) — можно с сохранением копирайта.
- 2026-10-26: auto-resolve сравнивает стороны с базой, когда конфликтные маркеры содержат BASE (Git `merge.conflictStyle=diff3` или `zdiff3`); без BASE автоматически выбираются только идентичные или пробельно-эквивалентные варианты. Несовпадающие изменения остаются на ручное разрешение.
- 2026-10-26: автопроверки пройдены: typecheck, lint, 60 unit/integration-файлов (540 passed, 1 skipped), полный E2E (45/45 suites) и целевой conflicts E2E на финальном коде.
