# T-020. Детали коммита и встроенный diff

## Цель

Просмотр изменений внутри приложения: выбор коммита → его метаданные и список файлов → diff
выбранного файла во встроенном редакторе. То же для рабочей копии (unstaged и staged).
Основа для индексации фрагментов (T-021) и разрешения конфликтов (T-025).

## Как это сделано в GitKraken (разбор 2026-10-22)

- Список файлов коммита — из дельт nodegit (`Diff` → `patches()`): статус, флаг бинарности
  (`Diff.FLAG.BINARY`), опции `SHOW_BINARY`, `IGNORE_WHITESPACE`.
- Просмотр — Monaco `createDiffEditor` с полным содержимым обеих версий; режимы **Split** и **Inline**
  (`renderSideBySide`), `ignoreTrimWhitespace`, word wrap, навигация `goToDiff('next'|'previous')`.
  Правая сторона редактируема для рабочей копии.
- Отдельно есть **File View** (файл целиком) и **Hunk View** (только фрагменты с заголовками и кнопками
  Stage/Unstage/Discard Hunk, Stage selected lines); кнопки — свои оверлеи поверх Monaco по `getLineChanges()`.
- Hunk'и считаются в JS библиотекой `diff` (jsdiff, `structuredPatch`) по полным текстам, индексация
  фрагмента — применение патча к версии из индекса (`applyPatch`) и запись в индекс.

## Решения

- Данные diff не кладутся в реплицируемое состояние (они большие и нужны одному окну): отдельные
  IPC-запросы `commit:details` и `diff:file`, выбор коммита/файла — локальное состояние окна.
- Содержимое версий — blob'ы через nodegit (HEAD, индекс) и файл с диска (рабочая копия).
- Monaco из npm (`monaco-editor`), собирается Vite; только `editor.worker`, языки — встроенная
  подсветка Monarch. Никаких CDN (CSP и офлайн-работа).
- Лимит размера одной версии — 10 МБ; бинарные файлы не показываются как текст.
- Hunk View (свой рендер фрагментов с кнопками) — в T-021 вместе с индексацией; здесь — Split/Inline
  и сворачивание неизменённых участков средствами Monaco (`hideUnchangedRegions`).

## Этапы

- [x] Git-сервис: `commitDetails(root, sha)` — метаданные, полное сообщение, файлы со статусами и
      `+/-` строк относительно первого родителя (корневой коммит — относительно пустого дерева), rename detection
- [x] Git-сервис: `fileDiff(root, target)` (`src/main/git/diff.ts`) для `commit` / `worktree unstaged` / `worktree staged`:
      текст, бинарность, «слишком большой», «нет версии» (добавлен/удалён)
- [x] IPC `commit:details`, `diff:file` с проверкой аргументов (sha, относительный путь)
- [x] Renderer: выбор коммита в списке, панель деталей коммита со списком файлов
- [x] Renderer: компонент `DiffView` на Monaco — Split/Inline, игнор пробелов, перенос строк,
      сворачивание неизменённого, следующее/предыдущее изменение, язык по расширению
- [x] Клик по файлу рабочей копии открывает встроенный diff; внешний редактор и внешний diff — вторичные кнопки
- [x] Тесты сервиса на временных репозиториях (`src/main/git/diff.test.ts`, 8): корневой, rename/added/deleted со счётчиками,
      merge-коммит, бинарный, рабочая копия/индекс, пустой репозиторий, лимит размера, symlink
- [x] Живая проверка через UI (CDP): 13/13 в dev и в упакованном AppImage, без ошибок в консоли и нарушений CSP
- [ ] Ручная проверка владельцем на своих репозиториях

## Критерии готовности

- Diff любого файла любого коммита и рабочей копии открывается внутри приложения за доли секунды на типичных файлах.
- CSP не ослаблен (воркер Monaco грузится как `'self'`).

## Нюансы

- Monaco: `monaco-editor` 0.57; экспорт `./*` → `esm/vs/*.js`. Корневой модуль тянет языковые сервисы
  (TS/JSON/CSS/HTML) со своими воркерами — собрана своя облегчённая точка входа `src/renderer/src/monaco/setup.ts`
  (API, diff editor, find, folding, clipboard, contextmenu…) + Monarch-подсветка всех языков (лениво, отдельными чанками).
- `exports` пакета дописывает `.js` к подпутям и прячет CSS — `codicon.css` подключён через alias `monaco-codicons` в Vite.
- 2026-10-22: при демонтаже diff editor'а падало `AbstractContextKeyService has been disposed` из меню-«желоба»
  (кнопки отката фрагмента). Отключено (`renderGutterMenu: false`, `renderMarginRevertIcon: false`) — свои действия
  над фрагментами будут в T-021; перед `dispose()` модели отвязываются (`setModel(null)`).
- 2026-10-22: React 19 lint (`set-state-in-effect`): выбор коммита/diff живёт в `RepoWorkspace` с `key={repo.root}`
  (сброс при смене репозитория без эффекта); `useCommand` хранит результат вместе с ключом запроса.
- Размер: рендерер ≈1 МБ JS + воркер Monaco 0.6 МБ + ленивые языки; AppImage 139 МБ (+1.5 МБ).
- Протокол `app://`: добавлены MIME `font/ttf`, `font/woff` (шрифт иконок Monaco).
- Для e2e: Monaco рендерит пробелы как `U+00A0` — нормализовать текст перед сравнением.
- Hunk View и File View из GitKraken — не в этой задаче: Hunk View в T-021 (вместе с индексацией).
