# T-024. Граф коммитов и виртуализация списка

## Цель

Наглядный граф веток рядом со списком коммитов, плавная прокрутка десятков тысяч коммитов.

## Этапы

- [ ] Раскладка графа (lanes) по `parents` — в main или worker, не в React-рендере
- [ ] Отрисовка: SVG или canvas в строках списка
- [ ] Виртуализация списка (например, `@tanstack/react-virtual`)
- [ ] Подгрузка истории порциями вместо фиксированных 1000 коммитов
- [ ] Выбор коммита → детали (файлы, diff) — отдельная задача после согласования

## Нюансы

- В GitKraken граф — отдельный пакет `@gitkraken/gitkraken-components` (проприетарный) — пишем свой.
- Репликация состояния гоняет срез `repo` целиком; при больших историях историю стоит вынести
  в отдельный срез или загружать по запросу, чтобы не копировать её при каждом изменении статуса.
