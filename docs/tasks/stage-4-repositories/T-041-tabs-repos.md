# T-041. Вкладки, недавние и поиск репозиториев

## Цель

Несколько открытых репозиториев во вкладках, недавние и избранные, поиск репозиториев на диске (`find-git-repositories`), восстановление вкладок при запуске.

## Контекст

- В GitKraken: Tabs 65 строк (по `strings.json`); их реализация — ориентир по поведению, код свой.

## Этапы

- [ ] Состояние: несколько репозиториев в main, активная вкладка; реплицируемое состояние по вкладкам
- [ ] Вкладки: открыть, закрыть, переупорядочить, Ctrl+Tab
- [ ] Экран «Repository Management»: недавние, избранные, поиск на диске
- [ ] Восстановление вкладок при перезапуске (настройки T-050)

## Критерии готовности

- Пять открытых репозиториев переключаются мгновенно; при перезапуске вкладки восстанавливаются
- Юнит/интеграционные тесты, `npm run typecheck`, `lint`, `test`, сквозной набор в `npm run test:e2e` — зелёные

## Нюансы

- Реплицируемое состояние сейчас один срез repo — потребуется пересмотреть структуру (не копировать все репозитории в окно при каждом изменении).
