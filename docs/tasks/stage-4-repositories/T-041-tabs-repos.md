# T-041. Вкладки репозиториев, восстановление сессии, недавние и поиск репозиториев

## Цель

Несколько открытых репозиториев во вкладках, как в GitKraken. **При запуске открываются те же
вкладки, что были при закрытии** (сейчас приложение всегда стартует без репозитория — замечание
владельца 2026-10-23). Экран управления репозиториями: недавние, избранные, поиск на диске.

## Контекст

- В GitKraken: вкладки (65 строк интерфейса), Repository Management, `find-git-repositories` (уже подключён у нас).
- Сейчас в main один срез `repo`; репликация копирует его в окно целиком.

## Этапы

- [ ] Состояние: `repos: Record<id, RepoState>` + `tabs: id[]` + `activeTab`; операции (`repo:*`, `index:*`,
      `commit:*`, `diff:*`) получают id репозитория явно, а не «текущий»
- [ ] Репликация: в окно — метаданные всех вкладок и полные данные только активной (не копировать все истории)
- [ ] Вкладки: открыть (в новой или текущей), закрыть, переупорядочить перетаскиванием, Ctrl+Tab / Ctrl+Shift+Tab,
      Ctrl+W, Ctrl+1…9; «+» открывает экран управления репозиториями
- [ ] **Восстановление сессии**: при выходе сохраняются вкладки и активная (настройка T-050, по умолчанию включено);
      при запуске репозитории открываются; недоступный путь — вкладка с объяснением и кнопкой «Убрать»
- [ ] Экран «Repositories»: недавние (с датой открытия), избранные (звёздочка), поиск git-репозиториев в выбранной
      папке (`find-git-repositories`, в фоне, с отменой), открытие по пути и перетаскиванием папки в окно
- [ ] Аргументы командной строки: `forklift <путь>` открывает репозиторий во вкладке (и во уже запущенном экземпляре
      через `second-instance`)
- [ ] Тесты: модель вкладок, сохранение/восстановление, несуществующие пути; сквозной набор (открыть 3 репо,
      перезапуск — вкладки на месте)

## Критерии готовности

- Перезапуск приложения возвращает вкладки и активный репозиторий; переключение мгновенное
- Юнит/интеграционные тесты, `npm run typecheck`, `lint`, `test`, сквозной набор в `npm run test:e2e` — зелёные

## Нюансы

- Задача меняет структуру состояния и IPC — делать **до** большинства функций этапов 2–3, чтобы не переделывать их.
- Вкладки разных репозиториев не должны мешать друг другу: очередь операций индекса (T-021) — по репозиторию.
