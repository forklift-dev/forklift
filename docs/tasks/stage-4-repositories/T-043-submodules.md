# T-043. Подмодули

## Цель

Подмодули: список, добавление, init/update, открытие подмодуля как репозитория, изменения подмодуля в панели изменений.

## Контекст

- В GitKraken: Submodule 102 строки (по `strings.json`); их реализация — ориентир по поведению, код свой.

## Этапы

- [x] Список и статус подмодулей
- [x] add / update --init --recursive / sync / удаление
- [x] Открыть подмодуль во вкладке
- [x] Тесты

## Критерии готовности

- Сценарии подмодулей проходят тестами и через UI
- Юнит/интеграционные тесты, `npm run typecheck`, `lint`, `test`, сквозной набор в `npm run test:e2e` — зелёные

## Нюансы

- 2026-10-23: список — раздел SUBMODULES в левой панели (`submodule:list`: `.gitmodules` + `git submodule
  status` + `status --porcelain=v2` для «изменён внутри»): путь, URL, состояние (не инициализирован / на
  записанном коммите / на другом коммите / конфликт). Вложенные подмодули видны, когда подмодуль открыт во
  вкладке (двойной щелчок или «Open in a new tab»).
- 2026-10-23: действия: «+» — add (`git submodule add`, URL и папка внутри репозитория; результат в индексе, его
  нужно закоммитить), Update / Initialize and update, Update all (`update --init --recursive`), Sync URLs
  (`sync --recursive`), Remove (`deinit -f` + `git rm` + удаление клона в `.git/modules/<имя>`; подтверждение).
  Сетевые — через askpass и NetworkOps (прогресс и Cancel в тулбаре/тосте, вид «Updating submodules»).
- 2026-10-23: в панели изменений подмодуль помечен значком; его diff — как у git: `Subproject commit <sha>`
  (рабочая копия — `<sha>-dirty`, если внутри есть изменения); раньше такой diff падал. Discard подмодуля —
  `submodule update --init --no-fetch` (возврат к записанному коммиту; изменения внутри не трогаются, без undo).
- 2026-10-23: Clone — флажок «Clone submodules too» (по умолчанию включён, `--recurse-submodules`).
- 2026-10-23: локальные пути как URL подмодулей git ≥ 2.38.1 запрещает (`protocol.file.allow=user`, защита от
  CVE-2022-39253); приложение это не ослабляет — тесты разрешают его только в своём окружении.
- 2026-10-23: попутно исправлено (T-040): в диалоге Clone/Init значения по умолчанию, пришедшие после ввода,
  затирали уже введённую папку; теперь введённое пользователем остаётся.
- 2026-10-23: проверено: юнит-тесты (`submodules.test.ts`: add, состояния, recursive update свежего клона, sync,
  remove, проверка путей, отметка и diff подмодуля) и сквозной набор `submodules` (11 проверок).
