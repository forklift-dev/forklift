# T-095. Удобный выбор upstream для ветки

## Цель

Показывать текущий upstream и выбирать удалённую ветку в отдельном понятном окне с поиском, рекомендацией одноимённой ветки и явным подтверждением. По примеру GitComet, из контекстного меню удалённой ветки можно назначить её upstream текущей локальной ветки.

## Этапы

- [x] Показать текущую связь и сгруппированные удалённые ветки, выделить подходящую одноимённую.
- [x] Добавить поиск, клавиатуру, подтверждение и снятие upstream.
- [x] Добавить действие «назначить upstream» на удалённой ветке.
- [x] Проверить сохранение выбора в Git и отображение после обновления.

## Критерии готовности

- Выбор upstream доступен из локальной ветки, а прямое назначение — из удалённой.
- Изменение или сброс upstream явно видны в интерфейсе и применяются только после действия пользователя.
- Существующий `branch:setUpstream` и проверка удалённой ветки остаются источником записи.

## Нюансы

- [Официальная документация GitComet](https://docs.gitcomet.dev/getting-started/undoing-a-merge/) описывает контекстное действие «Set as tracking upstream» на удалённой ветке; интерфейс Forklift реализован своим кодом.
- Целевой E2E `branches` проверяет выбор мышью, поиск с Enter, удаление связи и прямое действие на удалённой ветке.

## Промт

```text
Сделай удобный селектор upstream и прямое действие на удалённой ветке. Используй существующий IPC branch:setUpstream, покажи текущую связь, сделай поиск и управление с клавиатуры, проверь сценарий в E2E.
```
