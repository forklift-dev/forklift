# T-104. Рабочие места для задач

## Цель

Создание именованного рабочего места на базе worktree и ветки, открытие в собственной вкладке, связанный терминал и заметка о задаче. Не выполнять команды агента автоматически.

## Контекст

По решению владельца от 2026-10-28 функция экспериментальная: вся её UI-точка входа и связанные controls должны быть скрыты при выключенной настройке `general.experimentalFeatures`. Общий переключатель описан в [T-100](../stage-5-settings/T-100-experimental-features.md).

## Этапы

- [x] Добавить создание worktree/ветки с именем задачи и путём, отдельную карточку с заметкой и действия открытия worktree/терминала.
- [x] Сохранять названия и заметки в пользовательских данных; не запускать команды агента автоматически.
- [x] Добавить unit и e2e проверки, включая выключенный флаг.
- [x] Исправить слежение за связанным worktree, когда каталог Git находится вне корня рабочего дерева.
- [x] Прогнать typecheck, lint, i18n:check, unit и e2e сценарий branches.

## Критерии готовности

- Создание именованного рабочего места на базе worktree и ветки, открытие в собственной вкладке, связанный терминал и заметка о задаче. Не выполнять команды агента автоматически.
- При выключенных экспериментальных функциях никакая точка входа этой функции не отображается.
- При включении функция доступна, состояние корректно переживает перезапуск и соответствует настройке.
- Тесты и документация задачи обновлены.

## Нюансы

- 2026-10-28: владелец попросил сделать все четыре функции доступными только через явный opt-in в настройках.
- 2026-10-28: заметки ограничены 20 000 символами и сохраняются вне Git в пользовательском JSON-файле. Терминал открывается только по явному нажатию; команды не подставляются и не запускаются автоматически. Проверки выше проходят.
