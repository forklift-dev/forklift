# T-079. Группы репозиториев (fetch/pull для набора)

## Цель

Предложение (2026-10-26): именованные группы репозиториев на стартовом экране и во вкладках, общие fetch/pull (только fast-forward) с итогом по каждому — есть у AngKorGit (`src-tauri/src/core/group_update.rs`), запрашивается у обоих (GitComet #539, AngKorGit #68).

## Контекст

- Вкладки, недавние, избранное — T-041; auto-fetch — T-042.
- Облачные Workspaces GitKraken исключены решением владельца («Сознательно не делаем»); это локальные группы без сервера.

## Этапы

- [x] Группы: создать, переименовать, цвет, перетаскивание; открыть/закрыть группу целиком
- [x] Fetch all / Pull all (ff-only) с прогрессом и отменой, итог по репозиториям
- [x] Статус группы: что отстаёт, что с изменениями

## Критерии готовности

- Группа из 10 репозиториев обновляется одной командой с понятным итогом
- Юнит/интеграционные тесты, `npm run typecheck`, `lint`, `test`, сквозной набор в `npm run test:e2e` — зелёные
