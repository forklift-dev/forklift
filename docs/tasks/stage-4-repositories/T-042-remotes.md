# T-042. Удалённые репозитории и auto-fetch

## Цель

Управление remotes (добавить, переименовать, изменить URL, удалить), автоматический fetch по интервалу, prune, удалённые ветки в левой панели.

## Контекст

- В GitKraken: Remote 151 строка (по `strings.json`); их реализация — ориентир по поведению, код свой.

## Этапы

- [ ] CRUD remotes через GitCli
- [ ] Auto-fetch: интервал из настроек (по умолчанию 10 мин), пауза при неактивном окне, без запросов учётных данных в фоне
- [ ] Prune при fetch по настройке
- [ ] Тесты с локальными bare-репозиториями

## Критерии готовности

- Remotes управляются из UI; auto-fetch не мешает работе и не спрашивает пароли в фоне
- Юнит/интеграционные тесты, `npm run typecheck`, `lint`, `test`, сквозной набор в `npm run test:e2e` — зелёные
