# T-042. Удалённые репозитории и auto-fetch

## Цель

Управление remotes (добавить, переименовать, изменить URL, удалить), автоматический fetch по интервалу, prune, удалённые ветки в левой панели.

## Контекст

- В GitKraken: Remote 151 строка (по `strings.json`); их реализация — ориентир по поведению, код свой.

## Этапы

- [x] CRUD remotes через GitCli (добавить, переименовать, fetch/push URL, удалить) — левая панель, секция Remote
- [x] Auto-fetch: интервал из настроек (по умолчанию 10 мин), пауза при неактивном окне, без запросов учётных данных в фоне
- [x] Prune при fetch по настройке (General → Prune when fetching)
- [x] Тесты с локальными bare-репозиториями

## Критерии готовности

- Remotes управляются из UI; auto-fetch не мешает работе и не спрашивает пароли в фоне
- Юнит/интеграционные тесты, `npm run typecheck`, `lint`, `test`, сквозной набор в `npm run test:e2e` — зелёные

## Нюансы

- 2026-10-23: фоновый fetch не может ничего спросить: пустой `GIT_ASKPASS`/`SSH_ASKPASS` и
  `SSH_ASKPASS_REQUIRE=never` — работают только сохранённые данные (credential helper, ssh-agent). Если нужны
  учётные данные — одно уведомление «Use Fetch once to sign in», и auto-fetch этого репозитория ждёт, пока fetch
  не сделают вручную.
- 2026-10-23: fetch — только активной вкладки и только когда у окна фокус; открытие репозитория fetch не
  запускает (часы начинаются с первой проверки); ручной fetch/pull сбрасывает часы. Проверка — раз в 30 с.
- 2026-10-23: prune по умолчанию выключен — как в git (`fetch.prune` по умолчанию false).
- 2026-10-23: попутно исправлено: git 2.48+ при fetch создаёт `refs/remotes/<remote>/HEAD`, а nodegit
  `getReferences()` отдаёт его уже разрешённым под именем целевой ветки — удалённые ветки дублировались в панели
  и в метках графа. Теперь повторы по имени отбрасываются (тест).
- 2026-10-23: проверено: юнит-тесты (CRUD, фоновый fetch без askpass-сессии, логика AutoFetch с подменённым
  временем) и сквозной набор `remotes` (7 проверок). Сам таймер auto-fetch сквозным тестом не проверен
  (минимальный интервал — минута) — проверить вручную.
