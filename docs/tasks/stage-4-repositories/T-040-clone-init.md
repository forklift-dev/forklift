# T-040. Clone и init

## Цель

Клонирование по URL (HTTPS/SSH) с прогрессом и отменой; создание нового репозитория (init) с .gitignore и лицензией из шаблонов.

## Контекст

- В GitKraken: Clone 61, Init 21 строка (по `strings.json`); их реализация — ориентир по поведению, код свой.

## Этапы

- [ ] Диалог Clone: URL, папка назначения, имя; прогресс (`--progress`), отмена, учётные данные (askpass из T-024)
- [ ] Диалог Init: папка, ветка по умолчанию, шаблоны .gitignore/LICENSE (свои файлы шаблонов, не из GitKraken), первый коммит по желанию
- [ ] Открытие результата во вкладке
- [ ] Тесты: clone локального bare-репозитория, отмена, init с шаблонами

## Критерии готовности

- Clone и init проходят тестами и через UI
- Юнит/интеграционные тесты, `npm run typecheck`, `lint`, `test`, сквозной набор в `npm run test:e2e` — зелёные
