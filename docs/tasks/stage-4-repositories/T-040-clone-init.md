# T-040. Clone и init

## Цель

Клонирование по URL (HTTPS/SSH) с прогрессом и отменой; создание нового репозитория (init) с .gitignore и лицензией из шаблонов.

## Контекст

- В GitKraken: Clone 61, Init 21 строка (по `strings.json`); их реализация — ориентир по поведению, код свой.

## Этапы

- [x] Диалог Clone: URL, папка назначения, имя; прогресс (`--progress`), отмена, учётные данные (askpass из T-024)
- [x] Диалог Init: папка, ветка по умолчанию, шаблоны .gitignore/LICENSE (свои файлы шаблонов, не из GitKraken), первый коммит по желанию
- [x] Открытие результата во вкладке
- [x] Тесты: clone локального bare-репозитория, отмена, init с шаблонами

## Критерии готовности

- Clone и init проходят тестами и через UI
- Юнит/интеграционные тесты, `npm run typecheck`, `lint`, `test`, сквозной набор в `npm run test:e2e` — зелёные

## Нюансы

- Шаблоны .gitignore/лицензий брать из открытых источников с совместимой лицензией (github/gitignore — CC0); указать источник.
- 2026-10-23: шаблоны — `src/main/repos/templates.ts`: 9 наборов .gitignore (ОС, редакторы, Node.js, Python, Java,
  .NET, Go, Rust, C/C++) — короткие списки, составленные по образцу github/gitignore (CC0), не копия; можно
  отметить несколько, они склеиваются с заголовками. Лицензии — стандартные тексты SPDX короткого вида (MIT, ISC,
  BSD-2/3-Clause, Unlicense) с подстановкой года и владельца (по умолчанию `user.name` из git config). Длинные
  лицензии (Apache-2.0, GPL, MPL) не включены: их тексты на десятки КБ — при желании добавить файлами.
- 2026-10-23: кнопки «Clone…» и «New…» на экране Repositories. Папка по умолчанию — новая настройка
  General → «Folder for new repositories» (пусто — домашняя папка), рядом «Browse…».
- 2026-10-23: clone: `git clone --progress -- <url> <folder>` через `RemoteService` (askpass-сессия без вкладки,
  запросы учётных данных поверх диалога), один clone за раз, прогресс в `app.clone`. Папка должна не существовать
  или быть пустой (проверяется на лету, пока вводится). При ошибке/отмене созданная папка удаляется (git, убитый
  по отмене, сам не убирает); выбранная пустая — остаётся пустой. «Cancel clone» оставляет диалог открытым.
  Подмодули при клонировании (`--recurse-submodules`) — в T-043.
- 2026-10-23: init: `git init --initial-branch=<ветка>` в новой или существующей папке (но не в репозитории);
  существующие .gitignore/LICENSE не перезаписываются (предупреждение в notices). Первый коммит «Initial commit»
  содержит только созданные файлы (если их нет — пустой коммит), остальные файлы папки остаются неотслеживаемыми;
  хуки не запускаются (`--no-verify`). Если коммит не удался (нет имени/почты) — репозиторий всё равно открывается,
  причина — в notices.
- 2026-10-23: проверено: юнит-тесты `create.test.ts` (clone bare-репозитория через file:// с прогрессом, пустая
  папка, ошибка и отмена без остатков, init с шаблонами, существующие файлы, ошибки ввода) и сквозной набор
  `clone-init` (19 проверок: clone по HTTP с паролем в приложении, папка занята, отмена во время запроса пароля,
  init с .gitignore/MIT/первым коммитом).
