# T-005. Сквозные проверки в репозитории

## Цель

Перенести сквозные проверки (сейчас во временной папке) в репозиторий: общий харнесс запуска Electron с CDP и инспектором, изолированный профиль и HOME, `npm run test:e2e`. Без этого ночная работа не сможет надёжно ловить регрессии.

## Этапы

- [ ] `tests/e2e/harness.mjs`: запуск (dev-сборка или `E2E_BINARY`), изолированные `XDG_CONFIG_HOME`/HOME, xvfb + `--ozone-platform=x11`, CDP страницы и инспектор main, сбор ошибок консоли
- [ ] Перенести наборы: базовый UI, ProcessRunner, shell env, внешние инструменты, diff/merge tools, встроенный diff, индексация и коммит
- [ ] Помощники: создание временных репозиториев, клики мышью по элементу, ввод текста, ожидание условий, нормализация NBSP Monaco
- [ ] `npm run test:e2e` (все наборы) и `npm run test:e2e -- <набор>`; скриншоты при падении
- [ ] Не трогать запущенный у владельца экземпляр (свой профиль — блокировка единственного экземпляра)

## Критерии готовности

- `npm run test:e2e` проходит целиком на Linux; каждый новый UI-функционал добавляет свой набор
- Юнит/интеграционные тесты, `npm run typecheck`, `lint`, `test`, сквозной набор в `npm run test:e2e` — зелёные

## Нюансы

- Monaco рендерит пробелы как U+00A0; клики по Monaco — только настоящими событиями мыши (CDP Input).
