# T-004. Подпись и нотаризация дистрибутивов

## Цель

Дистрибутивы запускаются на актуальных ОС без предупреждений: macOS (Gatekeeper требует
подпись Developer ID и нотаризацию), Windows (SmartScreen, подпись Authenticode).

## Контекст

`electron-builder.yml`: `hardenedRuntime: true` для macOS уже включён. Сертификатов пока нет.

## Этапы

- [ ] Решение владельца: нужны ли подписанные сборки и на каком этапе
- [ ] macOS: Developer ID Application, entitlements для hardened runtime (JIT для V8), нотаризация
- [ ] Windows: сертификат подписи (или облачная подпись), подпись установщика и `.node`-модулей
- [ ] Linux: подпись не обязательна; при публикации — контрольные суммы
- [ ] Встроить в CI (T-003), секреты — только в хранилище CI

## Критерии готовности

- Установка на чистых macOS и Windows без предупреждений о неизвестном разработчике.

## Нюансы

- Нотаризация проверяет все бинарники внутри `.app`, включая `nodegit.node` и `nsfw.node` —
  они должны быть подписаны той же командой.
