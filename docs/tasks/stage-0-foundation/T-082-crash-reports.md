# T-082. Отчёты о падениях (локально)

## Цель

Предложение (2026-10-26): при падении приложения (main, окно, служебные процессы) сохранять отчёт локально и при следующем запуске предлагать открыть issue с предзаполненным текстом — без телеметрии и отправки куда-либо. Так делает GitComet (`crates/gitcomet-app/src/crashlog.rs`, идея).

## Контекст

- Журнал операций — T-054; Electron crashReporter (minidump) — пока не включён.

## Этапы

- [ ] Маркер сессии, перехват необработанных ошибок main/renderer, падений служебных процессов
- [ ] Отчёт: версия, ОС, стек, последние операции журнала (без путей и секретов — маскировать)
- [ ] При следующем запуске — уведомление «Forklift завершился с ошибкой» и кнопка «Создать issue» (в репозитории проекта — решить с владельцем)

## Критерии готовности

- Падение воспроизводится в тесте и даёт отчёт при следующем запуске
- Юнит/интеграционные тесты, `npm run typecheck`, `lint`, `test`, сквозной набор в `npm run test:e2e` — зелёные

## Нюансы

- 2026-10-26: **вопрос владельцу**: куда вести кнопку «Создать issue» (GitVerse/GitHub-репозиторий проекта).
