# T-031. История файла и blame

## Цель

История изменений одного файла (с учётом переименований) и построчное авторство (blame) во встроенном редакторе.

## Контекст

- В GitKraken: FileHistory 19, Blame 7 строк (по `strings.json`); их реализация — ориентир по поведению, код свой.

## Этапы

- [ ] `git log --follow` для файла: список коммитов, diff файла в каждом
- [ ] Blame: `git blame --porcelain` (или nodegit Blame), колонка автор/дата/коммит рядом с текстом в Monaco
- [ ] Переход из строки blame к коммиту в графе; blame на любой ревизии
- [ ] Точки входа: контекстное меню файла в панели изменений, в деталях коммита, палитра команд

## Критерии готовности

- История и blame открываются для файла с 10 000 строк за разумное время, без зависания окна
- Юнит/интеграционные тесты, `npm run typecheck`, `lint`, `test`, сквозной набор в `npm run test:e2e` — зелёные
