# T-073. Bisect

## Цель

Пожелание владельца (2026-10-26): git bisect в интерфейсе — отметить хороший и плохой коммиты, проходить шаги, видеть оставшийся диапазон в графе, при желании — запуск скрипта (`git bisect run`). Ни у AngKorGit, ни у GitComet bisect нет (только индикатор состояния).

## Контекст

- Операции над коммитами и баннер текущей операции — T-032/T-033 (`OperationBanner`); состояние BISECT_LOG уже отслеживается наблюдателем.

## Этапы

- [x] Начать из контекстного меню коммита (good/bad), баннер с шагом и числом оставшихся
- [x] Пометки good/bad/skip в графе, затемнение исключённых коммитов
- [x] `git bisect run` с командой и выводом (как хуки), остановка
- [x] Итог: найденный коммит, сброс (`bisect reset`), журнал (`bisect log`)

## Критерии готовности

- Сквозной набор: история с внесённой ошибкой, bisect вручную и через run находит коммит
- Юнит/интеграционные тесты, `npm run typecheck`, `lint`, `test`, сквозной набор в `npm run test:e2e` — зелёные

## Нюансы

- 2026-10-27: Состояние bisect читается из служебных файлов и refs Git при каждом обновлении, поэтому сохраняется после перезапуска приложения. `bisect run` принимает исполняемую программу и аргументы по одному на строку; команда не проходит через оболочку.
- 2026-10-27: Отмена останавливает дерево процессов тестового скрипта. Сессия bisect остаётся активной, её можно продолжить или завершить кнопкой сброса.
- 2026-10-27: Интеграционные тесты проверяют ручные отметки в обоих порядках, skip, отмену, автоматический поиск и сброс. Сквозной тест проверяет меню, баннер, граф, ручной и автоматический поиск.
- 2026-10-27: Проверки: `npm run typecheck`, `npm run lint`, `npm test` (545 пройдено, 1 пропущен), `npm run test:e2e` (46/46 наборов). После последней правки меню отдельно повторно прошли наборы `bisect` и `commit-ops`.
