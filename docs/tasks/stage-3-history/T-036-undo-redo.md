# T-036. Undo/Redo операций

## Цель

Отмена и повтор последних операций (коммит, checkout, создание/удаление ветки, reset, discard, stash), как Undo/Redo в GitKraken.

## Контекст

- В GitKraken: Undo/Redo 20 строк (по `strings.json`); их реализация — ориентир по поведению, код свой.

## Этапы

- [ ] Журнал операций с тем, что нужно для отмены (sha, имя ветки, содержимое discard)
- [ ] Отмена через reflog/ORIG_HEAD/восстановление ветки; discard — из сохранённой копии (до 50 МБ)
- [ ] Кнопки Undo/Redo в тулбаре, Ctrl/Cmd+Z / Shift+Ctrl/Cmd+Z вне редакторов
- [ ] Понятные пределы: что нельзя отменить (push), — объяснение

## Критерии готовности

- Каждый тип операции отменяется и повторяется в тестах
- Юнит/интеграционные тесты, `npm run typecheck`, `lint`, `test`, сквозной набор в `npm run test:e2e` — зелёные
