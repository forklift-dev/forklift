# T-078. Сравнение двух коммитов и веток

## Цель

Предложение (2026-10-26): выделить два коммита (Ctrl+клик) или две ветки и увидеть diff между ними — частый запрос у обоих конкурентов (AngKorGit #55, GitComet #123).

## Контекст

- Детали коммита и diff — T-020; выделение в графе — T-022.

## Этапы

- [x] Выделение двух коммитов в графе (Ctrl/Cmd+клик), панель сравнения: список файлов и diff
- [x] Сравнение веток/тегов из меню и палитры (`A...B` и `A..B`)
- [x] Открыть файл в diff, история файла между точками

## Критерии готовности

- Сквозной набор: два коммита и две ветки сравниваются, diff совпадает с `git diff`
- Юнит/интеграционные тесты, `npm run typecheck`, `lint`, `test`, сквозной набор в `npm run test:e2e` — зелёные

## Нюансы
- 2026-10-26: решение владельца: делаем; порядок владельца (2026-10-26): T-080 → T-078 → T-076 → T-077, затем T-079 и T-084.
- 2026-10-27: `A..B` сравнивает деревья самих коммитов; `A...B` — дерево общего предка с B. Общий предок находится через `git merge-base`; список файлов, переименования и счётчики строк — через тот же nodegit diff, что используется в деталях коммита. История файла ограничена диапазоном `base..B`.
- 2026-10-27: Ctrl/Cmd+клик по второй строке графа или ссылке в боковой панели открывает сравнение; контекстное меню коммита/ветки/тега предлагает оба режима. Палитра команд открывает выбор двух ссылок или выбранного коммита и режима. В графе подсвечены обе точки.
- 2026-10-27: интеграционные тесты проверяют расхождение веток и содержимое файла, сквозной набор `compare` — оба режима, diff, диапазон истории, меню и палитру.
