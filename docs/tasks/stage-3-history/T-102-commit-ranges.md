# T-102. Операции над диапазоном коммитов

## Цель

Выбор границ диапазона в графе, предварительный просмотр состава и безопасные действия сравнить, cherry-pick или revert с понятным порядком и остановкой при конфликте.

## Контекст

По решению владельца от 2026-10-28 функция экспериментальная: вся её UI-точка входа и связанные controls должны быть скрыты при выключенной настройке `general.experimentalFeatures`. Общий переключатель описан в [T-100](../stage-5-settings/T-100-experimental-features.md).

## Этапы

- [x] Добавить выбор двух границ диапазона, предпросмотр, лимит в 500 коммитов и cherry-pick/revert с остановкой при конфликте.
- [x] Добавить unit и e2e проверки; controls скрыты без экспериментального режима.
- [x] Прогнать typecheck, lint, i18n:check, unit для commitOps и e2e-сценарий branches.

## Критерии готовности

- Выбор границ диапазона, предварительный просмотр состава и действия cherry-pick/revert с понятным порядком и остановкой при конфликте.
- При выключенных экспериментальных функциях никакая точка входа этой функции не отображается.
- При включении функция доступна, состояние корректно переживает перезапуск и соответствует настройке.
- Тесты и документация задачи обновлены.

## Нюансы

- 2026-10-28: владелец попросил сделать все четыре функции доступными только через явный opt-in в настройках.
- 2026-10-28: реализовано в графе и панели диапазона; preview показывает максимум 500 коммитов. Проверки: `typecheck`, `lint`, `i18n:check`, 12 unit-тестов commitOps и e2e `branches` проходят.
