# T-076c. Отдельное окно Forklift для git mergetool

## Цель

Разрешать git-конфликт в отдельном окне Forklift, используя BASE, LOCAL, REMOTE и MERGED, полученные от Git.

## Контекст

Редактор конфликтов T-025/T-072 работает с индексом репозитория; внешний `git mergetool` передаёт временные файлы и ждёт завершения. Внешнее окно не должно запускать операции git поверх основного редактора конфликта.

## Этапы

- [ ] Показать BASE/LOCAL/REMOTE и редактируемый результат MERGED в отдельном окне.
- [ ] Сохранять только в переданный MERGED путь; не менять другие файлы и не записывать файлы при отмене.
- [ ] Поддержать совместимые позиционные аргументы KDiff3/Meld и сообщать Git об отмене/ошибке ненулевым кодом.
- [ ] Проверить конфликтный и бесконфликтный вызовы `git mergetool`, отмену, пробелы в путях и запуск рядом с основным окном.

## Критерии готовности

- Git получает разрешённый файл только после явного сохранения результата; успешный выход принимается согласно `trustExitCode`.
- BASE/LOCAL/REMOTE соответствуют сторонам Git; отмена не записывает результат и сообщает неуспех.

## Нюансы

- 2026-10-27: не использовать служебный `*.orig` файл Git; его создание контролируется пользовательской настройкой `mergetool.keepBackup`.
