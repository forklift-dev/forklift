# T-093. Сохранение новых Git-настроек при удалении интеграции

## Цель

Удаление интеграции Forklift не должно перезаписывать значения Git config, которые пользователь изменил после установки.

## Этапы

- [x] Сравнивать текущие значения с установленными Forklift.
- [x] Сохранять изменённые значения и сообщать об этом в CLI.
- [x] Проверить сценарий с повторным изменением конфигурации.

## Критерии готовности

- Старые значения восстанавливаются только там, где до удаления остались значения Forklift.

## Нюансы

- Для существующих записей резервной копии прежнего формата используются известные значения Forklift; прочие текущие значения сохраняются.

## Промт

```text
Сделай uninstall Git tool setup безопасным для последующих правок пользователя и проверь его на временном репозитории.
```
