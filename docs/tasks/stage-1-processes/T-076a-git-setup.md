# T-076a. CLI и безопасная настройка Git для Forklift tools

## Цель

Поддержать команды `forklift difftool`, `forklift mergetool`, `forklift setup` и `forklift uninstall`; настройка Git должна сохранять прежние значения и позволять проверить изменения до записи.

## Контекст

Основное приложение сейчас запускается через single-instance lock, а argv обрабатывается в `src/main/repos/argv.ts`. Git tool invocation описана в T-076; основное приложение и его постоянная сессия должны оставаться изолированы от режимов инструментов.

## Этапы

- [x] Разобрать именованные аргументы CLI в чистой функции с проверкой обязательных путей; покрыть некорректные и повторные аргументы.
- [x] Обрабатывать команды настройки отдельным процессом приложения без передачи их обычному окну через single-instance lock.
- [x] Реализовать `setup [--local] [--dry-run]` и `uninstall`; перед записью показать план, сохранить/восстановить предыдущее состояние конфигурации, не менять пользовательские настройки инструментов вне своей области.
- [x] Проверять quoting исполняемого пути с пробелами и Git-переменных `$LOCAL/$REMOTE/$BASE/$MERGED`.

## Критерии готовности

- Parser tests покрывают неполные, повторные и неизвестные аргументы, абсолютные и относительные пути Git, пробелы в именах.
- `--dry-run` ничего не пишет; uninstall возвращает прежние значения и удаляет только конфигурацию Forklift.
- Unit/integration tests используют временный git config, не затрагивая config разработчика.

## Нюансы

- 2026-10-27: формат установки Git config должен учитывать, что `difftool.<name>.cmd` запускается оболочкой Git; не формировать его простой конкатенацией непроверенных путей.
- 2026-10-27: совместимость с внешними позиционными формами KDiff3/Meld проверяется в T-076b/T-076c, где известны конкретные вызовы соответствующего режима.
- 2026-10-27: `setup` по умолчанию работает с global config, `--local` — с конфигом репозитория; `--dry-run` только печатает план. Backup хранится в `forklift.setup.backup` той же области и возвращает предыдущие значения ключей при `uninstall`. Прямая проверка собранного dev-приложения подтвердила, что `setup --local --dry-run` завершается без открытия обычного окна.
- 2026-10-27: проверки: typecheck, lint, 11 unit/integration tests и e2e `git-tool-setup` (dry-run, установка поверх старых значений, отказ от повторной установки, восстановление uninstall при открытом основном окне).
- 2026-10-27: CLI для difftool разрешает относительные Git пути от cwd репозитория; e2e Git вызов проверен в T-076b.
