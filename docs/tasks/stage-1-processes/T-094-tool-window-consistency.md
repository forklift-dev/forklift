# T-094. Локализация и ограничение текста в отдельных окнах Git tools

## Цель

Отдельные окна diff и merge должны использовать язык приложения и не передавать в Monaco десятки мегабайт текста.

## Этапы

- [x] Передавать язык настройки в отдельные окна и перевести подписи.
- [x] Ограничить показываемый текст 2 МиБ; не разрешать сохранять неполный merge.
- [x] Проверить большие файлы и оба языка.

## Критерии готовности

- Подписи соответствуют выбранному языку; большие файлы не загружаются целиком в редактор.

## Нюансы

- Язык читается из сохранённых настроек; при ошибке чтения используется язык системы. Большие файлы показываются частично в diff, а merge не даёт сохранить неполный текст.
- Проверки чтения большого файла, typecheck, lint и целевые E2E для обоих окон прошли.

## Промт

```text
Приведи отдельные git diff/merge окна к локализации приложения и безопасному лимиту текста для Monaco.
```
