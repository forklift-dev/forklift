# T-092. Предупреждение о несохранённом merge

## Цель

При закрытии отдельного окна merge с изменённым результатом предложить сохранить работу или продолжить редактирование.

## Этапы

- [x] Отслеживать изменение результата.
- [x] Перехватывать Esc, кнопку отмены и закрытие окна.
- [x] При отмене закрытия сохранять введённый текст.

## Критерии готовности

- Несохранённые изменения нельзя случайно потерять при закрытии.

## Нюансы

- Окно получает флаг изменения по IPC; системное закрытие перехватывает main process. Чистое окно закрывается без вопроса. Ручная проверка диалога ещё нужна.

## Промт

```text
Добавь защиту от потери несохранённого результата в отдельном git mergetool для всех способов закрытия окна.
```
