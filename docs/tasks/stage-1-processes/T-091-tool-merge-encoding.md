# T-091. Сохранение кодировки в отдельном окне merge

## Цель

Сохранение результата merge не должно удалять UTF-8 BOM или менять файл без явной правки пользователя.

## Этапы

- [x] Читать UTF-8 с сохранением BOM.
- [x] Проверить сохранение результата с BOM на временном файле.

## Критерии готовности

- Файл с BOM сохраняет его после чтения и записи через окно merge.

## Нюансы

- `TextDecoder` по умолчанию скрывает BOM; нужен `ignoreBOM: true`.
- Проверка байтового round-trip прошла в `toolFile.test.ts`.

## Промт

```text
Сохрани UTF-8 BOM при чтении и записи файлов в отдельном git mergetool. Добавь проверку сохранности байтов.
```
