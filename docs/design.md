# Дизайн интерфейса

Решение владельца (2026-10-23): ориентир — GitKraken Desktop; темы — несколько своих (T-051).
Берём раскладку и сценарии, а не графику: иконки — codicons (MIT, уже в проекте через Monaco), цвета — свои.

## Раскладка (как в GitKraken)

```
┌ Вкладки репозиториев ────────────────────────────────────────────────────────────┐
├ Тулбар: [репозиторий ▾] [ветка ▾]   Undo Redo │ Pull▾ Push Branch Stash Pop │ Terminal ⌕ ⚙ ┤
├ Левая панель ┬ Граф коммитов ─────────────────────────────────┬ Правая панель ─────┤
│ LOCAL        │ ветка/тег │ граф │ сообщение │ автор │ дата │ sha │ WIP: изменения    │
│ REMOTE       │ // WIP (n staged, m unstaged)                  │  или детали        │
│ PULL REQ.*   │ ● commit …                                     │  коммита           │
│ TAGS         │ ● commit …                                     │                    │
│ STASHES      │                                                │ форма коммита      │
│ SUBMODULES   │                                                │                    │
│ WORKTREES    │                                                │                    │
├──────────────┴────────────────────────────────────────────────┴────────────────────┤
│ Терминал (сворачиваемая панель, вкладки)                                             │
└──────────────────────────────────────────────────────────────────────────────────────┘
```
\* PULL REQUESTS — с интеграциями (этап 6).

- **Граф** — главный экран. Узел **WIP** («// WIP») сверху, когда есть незакоммиченные изменения; клик по нему
  открывает изменения справа. Колонки настраиваемые (показ/скрытие, ширина).
- **Diff** открывается **вместо графа** в центре (как сейчас), закрывается Esc/✕; режимы Split/Inline/Hunk/File.
- **Левая панель**: секции сворачиваются, фильтр по имени; двойной клик по ветке — checkout; перетаскивание
  ветки на ветку — меню Merge/Rebase; контекстные меню у всех элементов.
- **Правая панель**: изменения рабочей копии + форма коммита (сейчас) или детали выбранного коммита.
- **Тулбар**: частые действия с подписями, второстепенные — в меню; состояние операций (идёт fetch/push) — спиннер
  на кнопке.

## Принципы

- Всё действие доступно трёмя путями: кнопка/меню, контекстное меню, палитра команд (T-052) + сочетание клавиш.
- Разрушительные действия (discard, reset --hard, удаление ветки, force push) — подтверждение с фокусом на «Отмена».
- Долгие операции не блокируют интерфейс; прогресс и отмена.
- Плотность как у GitKraken: строка графа ~ 28 px, шрифт интерфейса 12–13 px, моноширинный для sha/кода.
- Доступность: фокус виден, управление с клавиатуры, контраст тем по T-051.
- Цвета только через токены темы (CSS-переменные), без «зашитых» значений в компонентах.
